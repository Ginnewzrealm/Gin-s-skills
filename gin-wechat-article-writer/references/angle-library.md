# 公众号长文写作切入角度库

> 本文档是 skill 知识库（references/）中的元方法论：定义长文开头与结构可复用的切入角度。每个角度包含：名称、定义、适用素材信号、匹配规则、结构模板、情绪触发点、客观评分项。外部 YAML 模板只引用角度 ID，不重复定义角度本身。
> 情绪触发体系见 `references/emotion-trigger-system.md`。

## 设计原则

1. **角度 = 稳定的认知杠杆**：不随具体选题变化，可以反复套用。
2. **素材信号驱动**：先诊断用户输入里有什么信号，再匹配角度，而非让 LLM 凭感觉选。
3. **情绪钩子贯穿**：每个角度必须绑定一个核心情绪触发点，指导标题、开头、正文和结尾设计。
4. **客观评分**：每个候选大纲用可计数、可存在性检查的清单打分，不依赖 LLM 主观评价。
5. **模板只决定演绎方式**：同一个角度在不同 YAML 模板（调查实验型 / 产品体验型 / 现象解读型 / 工具分享型 / 方法论分享型）中的具体写法不同。

## 素材信号定义

| 信号 | 识别规则 | 示例 |
|------|----------|------|
| 痛点 | 用户明确提到“困扰”“麻烦”“总是失败”“效率低”等负面情绪 + 具体场景 | “每次写周报都要花 2 小时” |
| 反常识 | 用户提出与主流认知冲突的判断，或提到“其实”“不是”“恰恰相反” | “真正好用的笔记软件，功能反而更少” |
| 数字 | 用户给出具体数字、比例、统计、对比 | “转化率从 3% 涨到 12%” |
| 故事 | 用户描述一段个人/他人的经历、时间线、转折 | “去年我被裁后，开始自己接项目” |
| 身份 | 用户给出明确的目标读者画像或自我标签 | “给 3 年内新手产品经理” |
| 教程 | 用户明确想要步骤、清单、方法、SOP | “怎么写一份合格的 PRD” |

> 识别规则必须可程序化：出现关键词 / 句式 / 数字模式即可判定为存在该信号，不需要 LLM 理解语义。

## 角度列表

### A1 痛点反转型

- **定义**：先放大读者熟悉的痛点，再给出意想不到的反转或解决路径。
- **适用模板**：调查实验型、产品体验型、方法论分享型。
- **素材信号要求**：必须包含「痛点」+ 至少一项「数字 / 反常识 / 故事」。
- **情绪触发点**：找共鸣（主）、当嘴替（次）
- **钩子公式**：具体痛点场景 → 情绪放大 → 反转预期
- **结构模板**：
  1. 开场：一个具体、可代入的痛点场景（用短句、画面感）。
  2. 转折：指出大家在这个痛点上通常错在哪（反常识）。
  3. 主体：用过程/实验/案例证明新路径有效。
  4. 收尾：把方法压缩成一句可执行的动作。
- **客观评分项**：
  - 痛点场景 ≤100 字且含第一人称或第二人称（+2）
  - 出现具体数字或对比（+2）
  - 主体段落 ≥3 个证据/案例节点（+2）
  - 结尾提供可执行动作（+2）
  - 未出现宏大叙事或 AI 腔（+2）

### A2 数字结果型

- **定义**：用一组令人意外的数字或结果直接开场，再用解释让数字落地。
- **适用模板**：调查实验型、现象解读型、工具分享型。
- **素材信号要求**：必须包含「数字」。
- **情绪触发点**：看结果（主）、辨真伪（次）
- **钩子公式**：抛出刺眼数字 → 制造"为什么"悬念 → 解释来源
- **结构模板**：
  1. 开场：抛出最刺眼的 1-2 个数字，制造“为什么”悬念。
  2. 背景：解释数字来自什么场景/实验/样本。
  3. 拆解：分 2-3 个原因解释数字背后的机制。
  4. 收尾：把数字转化为读者可复用的判断或行动。
- **客观评分项**：
  - 开头 50 字内出现 ≥1 个具体数字（+2）
  - 数字来源/样本在正文前 1/3 内说明（+2）
  - 原因拆解 ≥2 条且每条有证据支撑（+2）
  - 结尾给出读者可套用的判断标准（+2）
  - 避免“震惊体”式空洞感叹（+2）

### A3 认知冲突型

- **定义**：提出一个反常识判断，用证据把读者从原有认知拉到新认知。
- **适用模板**：现象解读型、方法论分享型、调查实验型。
- **素材信号要求**：必须包含「反常识」，建议同时包含「数字 / 故事」。
- **情绪触发点**：纠错欲（主）、辨真伪（次）
- **钩子公式**：大众旧认知 → 一句话反转 → 证据拉新认知
- **结构模板**：
  1. 开场：先说出大众普遍相信的观点。
  2. 冲突：用一句话反转这个观点。
  3. 论证：2-3 个层级的证据，从现象→机制→案例。
  4. 收尾：给出一个在新的认知下应该怎么做。
- **客观评分项**：
  - 前 80 字内明确呈现旧认知与新认知的冲突（+2）
  - 论证链条 ≥2 层（现象+机制 / 数据+案例）（+2）
  - 每个论点有来源或“我观察到”的限定（+2）
  - 结尾有可执行建议，而非纯观点（+2）
  - 没有出现“其实”“真相是”等廉价反转词滥用（+2）

### A4 故事代入型

- **定义**：用一段真实、具体的经历开场，把读者拉进场景，再自然引到观点。
- **适用模板**：产品体验型、工具分享型、方法论分享型。
- **素材信号要求**：必须包含「故事」。
- **情绪触发点**：找共鸣（主）、当军师（次）
- **钩子公式**：真实故事片段 → 意外/失败出现 → 抽离方法
- **结构模板**：
  1. 开场：一个有时间、地点、动作、情绪的小故事片段。
  2. 转折：故事中出现的意外/发现/失败。
  3. 主体：从故事抽离出可复用的方法/工具/观察。
  4. 收尾：回到读者场景，给出下一步建议。
- **客观评分项**：
  - 故事片段 ≤200 字且包含感官细节（动作/对话/情绪）（+2）
  - 故事中至少出现一次意外或转折（+2）
  - 主体从故事过渡到方法时有过渡句（+2）
  - 方法/工具部分有 ≥1 个具体使用场景（+2）
  - 结尾明确告诉读者“你可以先做什么”（+2）

### A5 身份共鸣型

- **定义**：开头直接点名目标读者身份，用“你”制造共鸣，再给出专属解决方案。
- **适用模板**：方法论分享型、工具分享型、现象解读型。
- **素材信号要求**：必须包含「身份」。
- **情绪触发点**：找共鸣（主）、当嘴替（次）
- **钩子公式**：点名身份 → 指出专属困境 → 给出方案
- **结构模板**：
  1. 开场：用一句“如果你也是……”直接框定读者。
  2. 痛点：指出这个身份最常遇到的具体困境。
  3. 方案：分步骤给出只对这个身份有用的方法/工具/视角。
  4. 收尾：用身份标签回扣，让读者有“被看见”感。
- **客观评分项**：
  - 开头 30 字内出现明确身份标签（+2）
  - 痛点与该身份强相关，非泛泛而谈（+2）
  - 方案步骤 ≤5 步，每步有动作指令（+2）
  - 每个步骤有“如果你不是这个身份，可以跳过”式说明（可选，+1）
  - 结尾回扣身份标签，形成闭环（+2）

### A6 清单教程型

- **定义**：直接给出一份可执行的清单或步骤，让读者能照着做。
- **适用模板**：工具分享型、方法论分享型。
- **素材信号要求**：必须包含「教程」。
- **情绪触发点**：当军师（主）、看结果（次）
- **钩子公式**：明确问题+人群 → 给出清单 → 常见坑提示
- **结构模板**：
  1. 开场：一句话说明这份清单解决什么问题、适合谁。
  2. 前置条件：列出使用清单前需要准备什么。
  3. 步骤主体：编号清单，每一步含动作、标准、常见坑。
  4. 收尾：给出检查自己是否做对的 2-3 个信号。
- **客观评分项**：
  - 开头明确“问题 + 适用人群 + 预期结果”（+2）
  - 步骤编号清晰，总数 ≤7（+2）
  - 每一步包含动作 + 判断标准（+2）
  - 至少包含 1 个“常见坑”提示（+2）
  - 结尾提供自检信号（+2）

### B1 轨迹描线法

- **定义**：通过追踪一个人、一件事、一个现象的完整轨迹，让读者看到“它从哪来、怎么变成这样、可能去哪”。
- **适用模板**：人物弧光型、商业观察型、公司命运型。
- **素材信号要求**：必须包含「故事」+ 至少一项「数字 / 反常识」；或有明显时间线/变化过程。
- **情绪触发点**：找结构（主）、找规律（次）
- **钩子公式**：他/它本来是这样 → 发生了一件事 → 变成了那样 → 不说好坏
- **结构模板**：
  1. 开场：呈现一个反常或关键的状态/结果。
  2. 回溯：交代理解这个状态必须知道的背景。
  3. 轨迹：按关键节点展示变化过程。
  4. 收尾：停在“人/事变成了什么”，不做二元判断。
- **客观评分项**：
  - 开头呈现反常状态或关键结果（+2）
  - 轨迹 ≥3 个可定位的关键节点（+2）
  - 每个节点有具体动作/数据/决策支撑（+2）
  - 不做“成功了/失败了”二元判断（+2）
  - 收尾停在“变成了什么”而非总结启示（+2）

### B2 处境代入法

- **定义**：让读者在人物或作者的处境里看到自己，产生“这个人遇到的困境和我有点像”的共鸣。
- **适用模板**：人物弧光型、深度随笔型。
- **素材信号要求**：必须包含「故事」+ 「痛点」；或有强烈情绪浓度的个人经历。
- **情绪触发点**：照镜子（主）、求治愈（次）
- **钩子公式**：这个人遇到的困境和我有点像 → 看看他怎么走出来的 → 不复制答案，只看路径
- **结构模板**：
  1. 开场：描述一个具体的处境或情绪状态。
  2. 共鸣：指出这个处境的普遍性。
  3. 路径：展示人物如何应对，不美化、不励志。
  4. 收尾：回到读者，给一种“被看见”的感受。
- **客观评分项**：
  - 开头 100 字内建立具体处境（+2）
  - 处境有普遍性，能让读者代入（+2）
  - 人物反应真实，无励志鸡汤（+2）
  - 主体展示过程而非直接给答案（+2）
  - 收尾让读者感到“被理解”而非“被教育”（+2）

### C1 棋局定位法

- **定义**：从单个现象或产品看到更大的趋势和棋局位置，回答“这件事意味着什么”。
- **适用模板**：AI产品故事型、商业观察型、现象解读型。
- **素材信号要求**：必须包含「反常识」或「数字」+ 可连接到更大背景的线索。
- **情绪触发点**：看到更远的棋（主）、找趋势（次）
- **钩子公式**：这个功能/现象表面看是 A → 深入看是 B → 说明行业正在往 C 方向走
- **结构模板**：
  1. 开场：从一个具体产品、现象或数据开始。
  2. 拆解：解释它为什么不是表面看起来那样。
  3. 定位：把它放到更大的行业/趋势棋盘里。
  4. 收尾：给读者一个可带走的新视角。
- **客观评分项**：
  - 开头从具体现象/产品切入（+2）
  - 拆解出至少一层“不是 A 而是 B”（+2）
  - 能把个案连接到行业/趋势（+2）
  - 收尾给出读者可复用的判断框架（+2）
  - 避免空泛宏大叙事（+2）

## 素材信号 → 角度 + 情绪触发点匹配规则

| 素材信号组合 | 优先匹配角度 | 备选角度 | 主情绪触发点 | 次情绪触发点 | 生成候选数建议 |
|--------------|--------------|----------|--------------|--------------|----------------|
| 痛点 + 数字 | A1 痛点反转型 | A2 数字结果型 | 找共鸣 | 当嘴替 | 2-3 |
| 痛点 + 故事 | A1 痛点反转型 | B2 处境代入法 | 找共鸣 | 照镜子 | 2-3 |
| 反常识 + 数字 | A3 认知冲突型 | C1 棋局定位法 | 纠错欲 | 看到更远的棋 | 2-3 |
| 故事 + 身份 | A4 故事代入型 | A5 身份共鸣型 | 找共鸣 | 当嘴替 | 2-3 |
| 故事 + 数字 | B1 轨迹描线法 | A2 数字结果型 | 找结构 | 找规律 | 2-3 |
| 身份 + 教程 | A5 身份共鸣型 | A6 清单教程型 | 找共鸣 | 当军师 | 2-3 |
| 数字 + 教程 | A2 数字结果型 | A6 清单教程型 | 看结果 | 当军师 | 2-3 |
| 产品/功能 + 数字 | C1 棋局定位法 | A2 数字结果型 | 看到更远的棋 | 看结果 | 2-3 |
| 仅有痛点 | A1 痛点反转型 | — | 找共鸣 | — | 1-2（提示补充素材） |
| 仅有故事 | A4 故事代入型 | B1 轨迹描线法 | 找共鸣 | 找结构 | 1-2（提示补充素材） |
| 仅有反常识 | A3 认知冲突型 | C1 棋局定位法 | 纠错欲 | 看到更远的棋 | 1-2（提示补充素材） |
| 仅有教程 | A6 清单教程型 | — | 当军师 | — | 1-2（提示补充素材） |

> 一个素材信号组合最多生成 2 个候选角度，避免候选过多。候选数量 = min(素材支撑角度数, 4)，但至少 1 个。每个候选必须明确标注主情绪触发点。

## 与 YAML 模板的关系

- **角度库**是稳定的：只定义“怎么切入”，不定义“写什么具体内容”。
- **YAML 模板**是风格插件：定义文章原型（调查实验型 / 产品体验型 / 现象解读型 / 工具分享型 / 方法论分享型）的结构、语气、禁区、视觉风格。
- 生成候选时，先按本角度库匹配角度，再用选定的 YAML 模板把角度演绎成具体大纲。

## 更新与扩展

- 新角度必须满足：有明确素材信号要求、有结构模板、有情绪触发点、有客观评分项，才能加入本库。
- 禁止把具体选题、行业术语、临时热点写入本库。
