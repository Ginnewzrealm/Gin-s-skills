# xie-ri-ji 更新日志

## 格式约定

- 每次升级技能后必须在本文件追加一条记录。
- 新记录写在最上方（倒序）。
- 每条记录包含：版本号、更新日期、变更类型、变更内容说明。
- 变更类型：`新增` / `优化` / `修复` / `重构` / `文档`。

## 更新记录
