# 目标值展示规则

## 何时展示目标差异

当用户主动报告带有数值的健身数据时，计算并展示与目标的差异。

例如：
- 用户说"今天吃了 1838kcal" → 展示目标热量差异
- 用户说"晨起体重 68.5kg" → 展示与上次记录的差异

## 展示格式

```
今日摄入：1838 kcal
目标热量：1936 kcal
差异：-98 kcal
```

## 注意事项

- 单日差异不做过渡解读，避免给用户造成焦虑
- 重点关注长期趋势，而非单日波动
- 差异展示仅作为参考，不替代专业建议

## 碳水循环目标展示

当碳水循环启用时，根据训练日/休息日展示不同目标：

```
今日：训练日
碳水目标：250g
```

训练日/休息日判断规则见 `knowledge/training-day-rules.md`。
