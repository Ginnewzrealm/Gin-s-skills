# 讯记 API 规则

## 定位

讯记是**可选的外部独立技能**，不是必须。本技能以桥接方式调用讯记 skill 获取数据，用于填充当日未录入的数据。

**桥接三原则**：不直连（讯记接口细节不出现在本技能）、不持有（不存不读不经手讯记凭证）、只桥接（检测安装 → 调用 → 接收结果）。职责边界详见 `skills/sync-xunji/SKILL.md`。

**禁止编造**：讯记数据缺失时，等待用户补充或留空，禁止估算、禁止编造。

## 调用时机

| 时机 | 调用目的 |
|------|---------|
| 最晚时段轮询时 | 填充当日未录入的训练数据 |
| 用户主动要求同步时 | 用户说"同步讯记" |
| 补数据时 | 补充指定日期的训练/身体/饮食数据 |

## 数据来源优先级

**核心规则：讯记数据永远不自动覆盖用户主动录入的数据。**

### 营养数据（热量/蛋白/脂肪/碳水）

- 用户自报 → 使用用户数据
- 用户未报且讯记有数据 → 使用讯记数据，字段标记 `记录来源=讯记同步`
- 讯记也无数据 → 本轮轮询不填充，等待用户补充

### 训练数据（训练日/休息日/训练内容）

- 用户自报 → 使用用户数据
- 用户未报且讯记有数据 → 使用讯记数据
- 讯记也无数据 → 根据每周训练频率（用户配置表）和日期推算训练日/休息日

### 身体数据（体重/体脂）

- 用户自报 → 使用用户数据，写入每日记录表
- 用户未报且讯记有数据 → 使用讯记数据，字段标记 `记录来源=讯记同步`
- 体重/体脂每次录入时同步更新用户配置表中的"当前体重"和"当前体脂"

## 讯记数据质量标记

当使用讯记数据时，在每日记录表中标记：

```
数据异常标记=讯记数据可疑
```

此标记供复盘层参考，不阻断流程。

## 依赖 skill

| skill | 数据类型 |
|-------|---------|
| xunji-body | 体重/体脂 |
| xunji-food | 饮食数据 |
| xunji-training | 训练数据 |

以上 skill 均为**外部独立安装**的可选依赖，不属于本技能包。检测方式：按技能名检测运行环境中是否已安装该 skill，**不在本技能包内查找其文件**（包内没有也不应有讯记 skill 的任何文件）。

如果某个讯记 skill 不可用：
1. 记录状态
2. 继续运行
3. 告知用户该 skill 未安装

## 错误处理

```
⚠️ 讯记同步不可用：xunji-training skill 未安装
原因：对应讯记 skill 未安装
操作：如需训练数据自动同步，请安装 xunji-training skill
影响：本 skill 继续运行，该类型数据需用户手动录入
```
