# 搞钱套路：知识付费与社群变现

## 模式概述

将个人经验、技能或信息差打包成课程或社群服务，通过流量变现。

## 核心要素

1. **人设打造**：专家、导师、成功者形象。
2. **引流产品**：免费资料、低价公开课、直播。
3. **高客单价产品**：训练营、私董会、1 对 1 咨询。
4. **交付方式**：录播课 + 微信群答疑 + 作业点评。

## 适用场景

- 用户有强烈的「搞钱」「提升自我」「解决焦虑」动机。
- 用户购买力中等，但对「改变命运」有支付意愿。

## 风险提示

- 交付重，容易变成「客服」。
- 复购率低，需不断拉新。
- 人设崩塌风险：收入依赖个人信誉，一次翻车全盘归零。

## 拆解要点（用于对标分析）

分析任何知识付费项目时，依次回答：

1. 流量从哪来？（投放 / 内容 / 转介绍）
2. 引流品到高价品的转化率是多少？
3. 交付人力成本占收入的比例？
4. 复购或转介绍机制是什么？没有 → 模式不可持续。
