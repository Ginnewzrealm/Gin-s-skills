# 用户画像：高净值人群

## 基础特征

- 年收入 50 万+，可投资资产 300 万+。
- 年龄 35-55 岁为主。

## 资源分配现状

- **时间**：极度稀缺，愿意花钱买时间（家政、专车、高端医疗）。
- **精力**：关注资产保值增值、子女教育、健康长寿。
- **金钱**：对价格不敏感，对品质、隐私、服务体验极度敏感。

## 支出优先级

- **P0**：健康（高端体检、抗衰老）、安全（保险、安保）、子女教育。
- **P1**：社交（高端俱乐部）、效率（私人助理）。
- **P2**：奢侈品（身份象征）。

## 搞钱套路

- 卖「稀缺性」和「圈层」。
- 卖「省时间」的服务。
- 卖「资产安全」的方案。

## 使用提示

- 目标人群与画像匹配时，直接用本文件校准动机与购买力判断。
- 不匹配时，以本文件为结构样板（基础特征 / 资源分配 / 支出优先级 / 搞钱套路）为新人群建立临时画像，并在报告附录 B 建议用户沉淀为新画像文件。

> 本文件是画像库示例。同目录下可累积更多画像文件，每个画像一个文件，结构保持一致。
