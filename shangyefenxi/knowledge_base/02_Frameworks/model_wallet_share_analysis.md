# 模型：用户钱包份额分析

## 目的

评估目标项目在用户消费结构中的真实地位，判断市场天花板和转化难度。是「需求 = 动机 + 购买力」公式中购买力维度的细化工具。

## 分析维度

### 1. 支出比例

- 目标用户在该领域的年度/月度总花费是多少？
- 该花费占其可支配收入的百分比？
- **判断**：比例过低说明市场太小或用户不重视；比例过高说明是刚需。

### 2. 支出优先级

当用户预算有限时，该需求排在什么位置？

| 优先级 | 含义 | 示例 | 抗风险能力 |
|---|---|---|---|
| **P0（必须买）** | 生存必需 | 吃饭、看病、刚需工具 | 强，经济下行也砍不掉 |
| **P1（想要买）** | 提升体验 | 娱乐、教育、改善型消费 | 中，受收入预期影响 |
| **P2（随便买）** | 冲动消费 | 小玩具、零食、情绪小物 | 弱，经济下行最先被砍 |

### 3. 资源分配观察（行为证据）

购买力判断必须有行为证据支撑，不听自述：

- **时间**：目标用户每天的时间花在哪？（如：睡前刷小红书 1-2 小时）
- **精力**：注意力持续投在什么主题上？（如：搞钱、副业、孩子教育）
- **金钱**：现有同类消费的实际金额和频次是多少？

## 输出格式

```
- 用户月均支出：[金额] [置信度标签]
- 占可支配收入比例：[百分比] [置信度标签]
- 支出优先级：[P0 / P1 / P2] [判断依据]
- 资源分配现状：[时间 / 精力 / 金钱的行为观察]
- 购买力判定：[成立 / 薄弱 / 不成立] + 依据
```

找不到支出数据时，标 `⏳ 待验证`，并在报告 §8 MVP 验证路径中设计对应的验证动作，**不编假设区间**。
