# 概念：真实需求公式

## 定义

判定一个需求是否成立，严格遵循以下公式：

**真实需求 = 强烈动机 + 实际购买力 + 可达触达路径**

## 解析

- **强烈动机**：用户想要解决某个痛点、满足某种欲望或完成某个任务的强烈程度。判断动机不看用户「怎么说」，看用户的时间、精力、金钱实际分配到了哪里。
- **实际购买力**：用户拥有支付能力，且愿意将资金分配给该解决方案。
- **可达触达路径**：存在一条成本可承受的通道，让解决方案真正抵达目标客户。需求再真、钱再多，触达不到就是空中楼阁。

## 判定标准

| 组合 | 判定 | 含义 |
|---|---|---|
| 有动机 + 有购买力 + 有触达 | 真实商业需求 | 值得做 |
| 有动机 + 有购买力 + 无触达 | 空中楼阁 | 客户够不着，先解决渠道问题 |
| 有动机 + 无购买力 | 伪需求 / 公益需求 | 无法商业化 |
| 无动机 + 有购买力 | 强推需求 | 教育成本极高，难做 |
| 无动机 + 无购买力 | 无效需求 | 直接放弃 |

## 应用场景

分析任何项目时，必须首先回答：

1. 用户的动机是什么？（用行为证据回答，不用自述回答）
2. 他们愿意且能够为此付多少钱？
3. 他们在哪里聚集？用什么渠道、花多少钱能接触到他们？

三者缺一，项目不可行——在报告中明确指出缺的是哪一环、依据是什么，但不下「做/不做」结论，决策权归用户。
