# lark 能力（飞书文档/表格读写）桥接约定

> 触发条件：本技能需要创建/读取飞书文档，或写入/读取飞书多维表格时
> 前置条件：用户环境中已安装 lark Skill 或 Lark CLI 至少其一

## 一、职责边界

调用方技能（本技能）负责：

- 检测 lark 能力的可用形态（lark Skill / Lark CLI）
- 构造调用参数（文档标题与正文、字段值、记录定位键）并发起调用
- 接收返回结果并按本技能规则使用与验证（写后复查、截断检测等）

被调用方（lark Skill / Lark CLI）负责：

- 飞书开放接口的鉴权、请求发送、限频控制与重试
- 返回结果的格式整理与错误信息返回
- 凭证的存储与管理（在其自身配置中）

本技能明确不执行以下操作：

- 不直接向飞书开放接口发起任何网络请求
- 不存储、不读取、不经手任何飞书凭证（App ID / App Secret / Token 等）
- 不实现任何重试逻辑（重试由 lark 能力内部负责）
- 不修改 lark 能力的行为逻辑，不代其实现领域功能

## 二、依赖检测

检测方式：写入飞书前依次检测——

1. 环境中 lark-doc / lark-drive Skill 是否可用；
2. 不可用则检测 Lark CLI 是否已安装（`command -v lark` 或等价方式）。

- **lark Skill 可用** → 级别 1：调用 lark Skill
- **Skill 不可用、Lark CLI 已安装** → 级别 2：调用 Lark CLI；命令、子命令与参数契约在运行时以 `lark --help` 自查为准
- **两者皆不可用** → 提醒用户安装 lark Skill 或 Lark CLI（说明安装途径），同时启用备用通道：级别 3 手动粘贴（生成符合字段要求的内容请用户粘贴），主流程不中断；**禁止直连飞书 API 代为实现，禁止模拟或伪造返回结果**

## 三、输入参数

> 以下为业务参数约定；lark Skill 的传参方式或 CLI 的具体命令行形式，调用时按被调用方当次自查的契约映射。

| 参数名 | 类型 | 必填 | 取值范围/格式 | 说明 |
|--------|------|------|---------------|------|
| 文档标题 | string | 是 | `{商机简称}｜商业可行性分析报告｜YYYY-MM-DD` | 文档轨：飞书文档标题 |
| 文档正文 | string | 是 | Markdown，10 节报告全文 | 文档轨：文档内容 |
| 目标文件夹 | string | 否 | `config.json` 的 `feishu_folder` 链接 | 文档创建位置；缺省云空间根目录并提醒补配置 |
| 表格链接 | string | 是 | `config.json` 的 `feishu_table` 链接 | 表格轨：目标多维表格 |
| 记录定位键 | string | 是 | 商机编号（两位数） | search→upsert：搜到更新、搜不到新建 |
| 字段值 | object | 是 | 字段名以运行时 field-list 读取为准 | A 组+B 组字段键值对；C 组留空 |

## 四、输出结果

| 字段名 | 类型 | 存在条件 | 说明 |
|--------|------|----------|------|
| 成功标志 | 依形态：Skill 返回值 / CLI 退出码 | 始终存在 | success 或退出码 0 = 成功，否则失败 |
| 文档链接 | string | 成功时 | 文档轨产物，写入报告与表格字段 3 |
| 记录定位 | string | 成功时 | 表格轨产物（记录 ID 或行标识） |
| 错误描述 | string | 失败时 | 用户可理解的错误原因，原样展示不得篡改 |

## 五、异常处理

| 异常情况 | 处理方式 |
|----------|----------|
| lark Skill 与 Lark CLI 均未安装 | 提醒安装并说明途径；降级手动粘贴，主流程不中断 |
| 调用返回失败 | 原样展示错误原因 → 按统一错误码+四行格式输出 → 降级手动粘贴；**不自动重试** |
| 返回缺文档链接/记录定位 | 对应项标注「待补充」，提示用户手动核对；禁止估算或编造 |
| 返回字段数量或长度异常（疑似截断） | 标截断风险，该字段降级手动粘贴 |
| 用户提出飞书侧配置/权限类需求 | 引导用户通过 lark 能力自行处理，本技能不代劳 |
