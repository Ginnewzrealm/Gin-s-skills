# 跟踪档案规范

> 创建或更新跟踪档案前必须读取本文件。档案路径：`{商机}/跟踪/跟踪_{商机名称}.md`

## 档案模板

```markdown
# 跟踪档案：{商机名称}

更新日期：YYYY-MM-DD

## 当前判断
（最新的工作性判断。有新结论直接覆盖更新，不留旧版本。）

## 待验证假设
（还没验证的假设列表。验证完就删除，结果写进「结果回填」。）

## 结果回填
（只追加。[结果回填 YYYY-MM-DD] 假设 X 的验证结果……）

## 跟踪日志
（只追加。每次咨询的关键结论，按日期倒序记录。）
```

## 更新规则

- **当前判断**：直接覆盖更新，不保留旧版本。
- **待验证假设**：完成即清，答案回流到「结果回填」。
- **结果回填 / 跟踪日志**：只追加，不改写已有条目。
- 用户确认或反驳 AI 推测时，更新当前判断，不保留旧结论的堆积。
