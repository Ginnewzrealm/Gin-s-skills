# 商机类型判定标准

> 报告模式阶段四使用本文件：输出报告与写入飞书字段 15「商机类型」前必须读取本文件，按标准判定三类之一。
> 三类：短期变现 / 长期价值 / 其他。判定结果写入报告「3 分钟摘要」的「商机类型」行（附一句判定依据），并以单选写入飞书字段 15。
> 本文件为用户提供的判定标准原文（2026-07-30），完整保留；类型名称按用户指示统一为「短期变现 / 长期价值 / 其他」（2026-07-30 更名）。

---

## 一、短期变现

**核心目标**：快速解决收入问题，4 周内收到第一笔钱，每月净收入 ≥ ¥5,000。

**投入维度**：

- 启动资金：≤ ¥5,000
- 技能要求：已有能力可直接交付，不需要长时间学习
- 工具要求：现成工具，不需要自研系统

**变现维度**：

- 定价明确，¥99-¥9,999 直接可报价
- 交付周期短，≤ 2 周完成交付
- 收款路径清晰，谈完/接单后即可收款
- 4 周内有明确第一笔收入

**本质**：赚时间差、平台红利或信息差。不恋战，快速验证，快速收款。

## 二、长期价值

**核心目标**：建立别人拿不走的护城河，换一张长期门票。

**护城河维度（满足任意一条）**：

- 网络效应：用户越多，产品、数据、撮合价值越高
- 数据壁垒：积累的数据资产别人无法复制
- 客户迁移成本：客户一旦用上，迁移代价极高
- 品牌口碑壁垒：先发建立的品牌效应
- 规模效应：做得越大，成本越低、利润越高
- 生态锁定：上下游都在体系内，离开代价大

**投入维度（满足任意一条）**：

- 时间：需要 6-18 个月建立期才能稳定月收
- 资金：需要 ¥50,000+ 启动资金
- 技能：需要特定行业认知、经验、年头积累
- 产品：需要自研系统、SaaS 或产品开发
- 资源：需要特定行业人脉或客户关系

**变现维度（同时满足）**：

- 跑通后月收入 ≥ ¥10,000
- 边际成本趋零（数字资产/订阅制），不是线性卖时间
- 收入稳定可预期，不依赖个人时间持续投入

**本质**：赚资产增值的钱，不是卖时间换钱。一旦建立，主动收入比例下降，被动收入比例上升。

**风险警示（符合任意一条需谨慎）**：

- 政策风险高，随时可能被监管叫停
- 技术迭代快，护城河建立在即将被替代的技术上
- 目标用户群在萎缩
- 核心资源不在自己手里

**快速自检（三个问题）**：

1. 别人复制一套一样的需要多久？6 个月以上 → 强护城河；1-2 个月能复制 → 弱护城河
2. 跑通之后是不是「起来了就不用再卖时间」？是 → 符合；否 → 不是真正的「长期价值」
3. 你能撑过前 6-18 个月吗？撑得过 → 可以做；撑不过 → 短期变现优先

## 三、其他

**核心定义**：这个项目暂时不是你的菜，不代表它本身不好。

**判定条件（满足任意一条归入「其他」）**：

**第一类：定义模糊或资料不足**

- 索引文件为空或只有待补充
- 无法判断变现模式和目标用户
- 需求真实性无法验证

**第二类：变现路径不清晰**

- 说了很多但不知道具体怎么收钱
- 收费模式难以落地
- 依赖环节太多，任一环节断掉就没收入

**第三类：需要特定资源或资质**

- 需要特定行业积累（制造业、医疗、法律等）
- 需要资质许可（营业执照、许可证等）
- 需要大额启动资金（¥10 万以上）
- 需要特殊技能短期内达不到

**第四类：需求真实性存疑**

- 目标用户不明确或群体极窄
- 用户付费意愿未验证
- 市场竞争已饱和或需求在萎缩

**第五类：合规风险或政策风险高**

- 平台政策明确限制
- 处于法律灰色地带
- 随时可能被封禁

**第六类：依赖平台长期积累才能变现**

- 必须先积累大量粉丝才能开始赚钱
- 平台一改算法就没收入
- 没有主动获客能力，只能等平台给流量

**第七类：和其他项目高度重叠**

- 在已有点位项目中处于被覆盖地位
- 没有独立存在价值
- 建议合并或放弃
