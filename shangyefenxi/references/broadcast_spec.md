# 进度播报话术示例

> SKILL.md「进度播报规则」的配套话术库。硬规则（触发播报 / 每节点最多一条 / 心跳 / 结束反馈）以 SKILL.md 为准；本文件只提供语气示例，可按场景微调措辞，风格保持亲切、带表情、一句话说完。

## 关键节点播报（报告模式）

| 节点 | 播报示例 |
|---|---|
| 路径确认 | `📁 工作根目录：{root}` |
| 开始采集资料 | `🔍 正在翻你的资料和分析文件夹，看看都放了什么…` |
| 资料采集完成 | `✅ 找到 N 份资料，开始消化啦` |
| 进入外部补研 | `🧠 开始外部补研，第 N 轮搜索中…` |
| 来源检查 | `🧐 在给关键事实查户口，看看有没有可靠来源…` |
| 断点存档 | `💾 进度已存进运行日志，随时能接着跑` |
| 进入分析管线 | `⚙️ 证据齐了，开始拆解商业模式…` |
| 报告生成 | `📝 报告写好了，正在做交叉校验和文字体检…` |
| 写入飞书 | `📊 正在把结果整理进飞书表格…` |
| 进入硬闸门 | `🚧 当前阻塞：等待你确认 XXXX。你可以回复「确认/继续」，或回复「修改/重来」回退。` |
| 正向复述等待确认 | `📝 我对项目的理解是这样：{复述摘要}。确认无误请回复「继续」，需要修改请直接说。` |
| 反向确认等待确认 | `🧭 我判定不属于本项目范畴的是：{边界清单}。有遗漏或不对请纠正。` |
| 用户要求回退 | `↩️ 收到，回退到 Step N，我们重新来。` |
| 完成 | `🎉 搞定！报告和飞书表格都更新好了` |

## 关键节点播报（咨询问答模式）

- 进入问答：`💬 已进入咨询问答模式，我会基于跟踪档案、可行性报告和横纵分析来回答。`
- 读取跟踪档案：`📖 先翻一下这个商机的跟踪档案，接上上次的判断…`
- 空转词识别：`⚠️ 「XXXX」在这句话里是空转词——你具体想获得什么？`
- 决策回填确认：`🚧 当前阻塞：等待你确认把「XXXX」写入飞书表格字段 9/12/14。确认吗？`
- 更新档案/回填：`💾 已把今天的结论存进跟踪档案，飞书表格也同步好啦`
