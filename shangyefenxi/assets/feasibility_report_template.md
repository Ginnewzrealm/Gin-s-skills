# 模板：商业可行性分析报告（10 节）

> 报告模式阶段四使用本模板输出。所有关键事实必须带双层标签：置信度（**✅ 已验证** / **⚠️ 行业基准** / **❓ 待验证**）+ 来源责任（[公开数据]/[AI 推测]/[AI 关键标注]/[AI 元记录]/[本人 反馈]）。
> 排版按密度分治：卡片式键值对用于定义类内容（1.1 / 3.1），表格用于数据密集内容，列表用于判断与建议；小节标题后已标注呈现形式。
> 章节序与飞书字段映射的 §1-§10 一一对应：第 N 节 = §N。
> 强制规则一：全文所有 [AI 推测] 与 ❓ 待验证条目，必须在 10.2 逐条汇总。
> 强制规则二：2.5 合规检查触雷（政策限制 / 资质不可得）时，3 分钟摘要「合规红线」行前置标明。
