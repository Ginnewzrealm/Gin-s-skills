# 爆款内容用户情绪触发系统

> 本文档是 skill 知识库（references/）中的元方法论，定义爆款内容背后的用户心理机制、加工 SOP 和自检清单。用于指导 angle-library、标题、大纲、正文、质检等环节设计情绪钩子。

## 核心心法

真正的爆款内容，本质上都是**"半成品"**。不要试图在内容里展现 100% 的完美，留出 30% 的缺口，邀请用户通过评论、转发来共同完成这个作品。你负责抛出诱饵，他们负责咬钩。

自媒体算法推荐机制（公众号、小红书、抖音等）核心考核指标：完播率/读完率、互动率（评论/点赞/转发）、停留时长。这七点情绪触发机制本质上都是在制造**"情绪缺口"**或**"认知冲突"**，强迫用户停下来思考或表达。

## 七点用户心理机制

| 触发点 | 用户心理 | 典型场景 | 加工动作 | 预期效果 |
|--------|----------|----------|----------|----------|
| 纠错欲 | 观众想纠正你 | 知识/观点类 | 找茬植入法 | 高评论率 |
| 看结果 | 悬念焦虑 | 叙事/挑战类 | 结果后置法 | 高完读率 |
| 看翻车 | 幸灾乐祸 + 好奇 | 挑战/实验类 | 高风险过程展示 | 高完读 + 评论 |
| 辨真伪 | 怀疑论 | 数据/现象类 | 反常识现象/极端数据 | 高评论率 |
| 当军师 | 好为人师 | 困境/半成品 | 示弱与留白法 | 高评论率 |
| 找共鸣 | 身份认同 | 痛点场景 | 场景代入法 | 高转发率 |
| 当嘴替 | 社交货币 | 价值观/评价类 | 替用户说出不敢说的话 | 高转发率 |

## 三种心理驱动力归纳

### 1. 认知冲突与纠错欲（对应点：纠错欲、看翻车、辨真伪）

- **观众想纠正你**：故意说错一个常识，或提出极具争议的观点。例如："我认为早起其实是毁掉一天的开始。"
- **观众想看翻车**：挑战类内容，"挑战 100 元在上海生存一周"。大家既希望成功，又期待看倒霉事。
- **观众想辨真伪**：揭秘类、打假类，或展示过于完美的东西。"这是真的吗？我不信。"

**逻辑原理**：利用用户的优越感、纠错本能、怀疑论心理。

### 2. 悬念与完结心理（对应点：看结果）

- **观众想看结果**：开头展示惊人的半成品或困境，过程曲折，最后才给答案。

**逻辑原理**：蔡格尼克效应（Zeigarnik effect），人们对未完成的任务记忆最深刻，也最渴望看到结局。

### 3. 自我投射与社交货币（对应点：当军师、找共鸣、当嘴替）

- **观众想给你支招**：展示困境、未完成的半成品，或两个难以抉择的选项。
- **观众想带入自己/证明自己**：内容说出了他们想说但不敢说的话，或展示了他们向往的生活。

**逻辑原理**：共鸣产生转发。用户转发你的内容，是为了塑造他们自己的人设（社交货币）。

## 系统输入端

启动这个工具，不能只输入"我想写什么"，必须输入经过加工的**"高势能素材"**：

1. **原始素材**：事实/事件、观点/结论
2. **用户画像数据**：认知水平、痛点与爽点、刻板印象
3. **预设的情绪钩子**：从七点中至少选择一个作为核心策略

## 系统处理逻辑：反差与缺口制造器

**核心公式**：

```
爆款内容 = (熟悉的话题 + 陌生的视角/错误的细节) × 强烈的互动诱因
```

**处理动作**：
- 故意暴露破绽
- 制造信息不对称
- 设置悬念
- 示弱留白

## 加工层 SOP

### SOP 1：找茬植入法（针对纠错欲 / 辨真伪）

1. 写出原本正确的文案。
2. 故意修改一个非核心但显眼的细节（如读错一个多音字、用错一个成语、或在一个专业领域提出看似外行的质疑）。
3. 或展示一个极其高风险的操作过程，制造"可能会出事"的紧张感。

**注意**：错误必须是显而易见的，不需要用户查字典才能发现。

### SOP 2：结果后置法（针对看结果 / 看翻车）

1. 把最精彩的结局、最惨烈的失败画面放到最后。
2. 开头展示一个"极度不平衡"的状态（如一堆乱糟糟的零件 vs 一张精美的成品图）。
3. 中间过程必须包含至少一次"意外"或"阻碍"，不能一帆风顺。

### SOP 3：示弱与留白法（针对当军师 / 找共鸣 / 当嘴替）

1. **示弱**：不要展示完美的专家形象。展示困惑、失败、纠结。例如："我试了三种方法都失败了，大家觉得第四步是不是有问题？"
2. **提问式结尾**：不要给确定结论。给出 A 和 B 两个选项，问用户："如果是你，你会选哪个？"
3. **场景代入**：描述极具普遍性的尴尬场景。不要写"工作很累"，要写"晚上 11 点关掉电脑，看着窗外发呆的 5 分钟"。

## 策略层：七维映射表

创作前，必须将原始素材强制归类到七个维度之一：

| 素材属性 | 适合触发点 | 加工动作 |
|----------|-----------|----------|
| 知识类 | 纠错欲、辨真伪 | 找茬植入法 |
| 叙事类 | 看结果、看翻车 | 结果后置法 |
| 技能/生活类 | 当军师、找共鸣 | 示弱留白法 |
| 观点/评价类 | 辨真伪、当嘴替 | 找茬植入法 / 场景代入法 |

**原则**：一条内容只能有一个核心触发点，贪多嚼不烂。

## 验证层：发布前致命三问

1. **前 3 秒/标题测试**：如果用户只给我 3 秒钟，我凭什么让他停下来？（是否有冲突、悬念或利益点？）
2. **槽点密度测试**：如果我是观众，看完后有评论的冲动吗？（如果内容无懈可击，用户只会划走。）
3. **互动门槛测试**：用户参与互动的成本是否足够低？（不需要长篇大论，只需几个字或表情包。）

## 自检清单

### 策略锚定

- [ ] 我是否故意留下了一个无伤大雅但显眼的"破绽"或争议观点？（纠错欲）
- [ ] 我是否把最精彩/最惨烈的结果后置，并在开头抛出了"极度不平衡"的状态？（看结果）
- [ ] 我是否展示了一个高风险、高难度的过程，让用户期待"意外"？（看翻车）
- [ ] 我是否展示了反常识的现象或极端数据，激发怀疑论心理？（辨真伪）
- [ ] 我是否抛出了一个具体困境、未完成的半成品，或两个难以抉择的选项？（当军师）
- [ ] 我是否描述了一个极具普遍性的痛点场景，让用户觉得"这说的不就是我吗"？（找共鸣）
- [ ] 我是否输出了用户想说但不敢说的强烈价值观？（当嘴替）

### 内容加工

- [ ] 错误/争议点是否足够显眼且易于发现？
- [ ] 前 3 秒/标题是否直接展示了"高潮画面"或"核心冲突"？
- [ ] 中间过程是否包含至少一次阻碍或意外？
- [ ] 结尾是否采用了"提问式"或"开放式"收尾？
- [ ] 细节描写是否足够具象？

## 更新与扩展

- 新触发点必须能对应明确的心理机制、加工 SOP 和可验证的互动效果，才能加入本库。
- 禁止把具体平台算法细节、临时热点写入本库。
