# 人物画像模型

在建立或深挖人物画像、检查人物设定厚度、执行全局一致性检查的人物一致性项时读本文件。

目标：把人物设计成"行为压力系统"，而不是"传记墙纸"。如果人物只能被概括成"聪明""高冷""善良"这类形容词，设计就还太薄。

## 主角八维（必填）

每个主角和核心反派，在 02-人物画像集.md 中必须有以下八维：

| 维度 | 要回答的问题 | 示例（古董店老板沈不言） |
|---|---|---|
| 表面欲望 | 他声称自己要什么 | 赚钱、捡漏、把店开大 |
| 隐藏需求 | 他真正缺什么（往往自己不承认） | 证明父亲当年不是疯子 |
| 恐惧 | 他最怕面对什么 | 看到自己最不想知道的记忆 |
| 羞耻点 | 他最不愿被人提起什么 | 父亲因追查古董记忆被当成精神病 |
| 债务 | 他欠谁的（人情/道德/血债） | 欠老师傅一条命 |
| 矛盾 | 他身上哪两件事互相打架 | 靠古董吃饭，却最怕古董说真话 |
| 压力反应 | 压力上升时他先做什么（攻击/逃避/插科打诨/过度控制……） | 先插科打诨，再独处追查 |
| 语言签名 | 他说话的节奏与习惯（来自教育、阶层、克制程度） | 行话满嘴，从不把话说满 |

另加两条可选深化：

- 盲区：他系统性低估什么（如：低估普通人卷入后的代价）
- 弧光方向：故事结束时他可能变成什么样（或付出什么代价拒绝改变）

## 配角简版（ recurring 配角）

每个会反复出场的配角至少有：

- 私人欲望（他自己想要什么，与主角无关的那部分）
- 来自世界的压力（什么在挤他）
- 与主角的关系及关系压力
- 一条"离开镜头也会自己推进"的行动线

如果配角只为建议、营救、吹捧、使绊而存在，重建他。

## 反派特别条款

核心阻碍若为人或组织（来自 00-灵魂页的 🚧 槽），必须额外展开：

- **它自己想要什么**（反派对抗目标，不是"阻止主角"而是"它自己的梦想"）
- 它的进度条：它也在推进自己的计划，与主角构成双向博弈
- 它哪里是对的：反派立场中站得住的那部分（没有这一条，反派容易写成纸片）

此条款的产物直接喂给定稿交接包的"反派对抗目标"字段。

## 关系即人物

人物通过关系显形。入档新人物时，顺手回答：

- 谁看得懂他 / 谁误读他
- 谁能戳中他的羞耻点 / 谁会诱发他最坏的模式
- 谁让改变成为可能

## 厚度门槛（入档前检查）

Reject 一个人物设计，如果：

- 欲望是通用的（"想过好日子"）
- 阻碍全是外部的，内心无缺口
- 没有羞耻、债务或矛盾
- 压力反应答不上来
- 所有配角承担同一种叙事功能

## 漂移警报（后续轮次检查用）

出现以下迹象，说明人物正在漂移，触发波及检查并报告用户：

- 人物做了剧情方便但无铺垫的举动
- 说话风格无原因地变了
- 欲望因为"大纲需要"而变更
- 重大压力事件后没有留下任何情绪痕迹
