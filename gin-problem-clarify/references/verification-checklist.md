# 第八步 验证与迭代清单

清单输出后立即启动验证，结果反馈到对应步骤。

## 四种验证方式

### 1. 用户回访

拿清单中的问题问目标用户：

> 「这些问题是你想知道的吗？」

- 通过：≥ 70% 用户回答「是」或「部分是」
- 不通过：< 70% → 回到第五步（澄清环节）优化问题表述

### 2. 专家审核

请领域专家审阅清单，判断：

- 问题是否准确
- 有无遗漏重要问题
- 优先级排序是否合理

通过：专家评分 ≥ 4 分（5 分制）
不通过：< 4 分 → 回到第四步（判定环节）修正标准

### 3. 覆盖率检查

检查 7 个维度（基础认知/实操方法/适用人群/常见障碍/效果评估/风险与边界/进阶路径）是否都有问题覆盖。

通过：每个维度 ≥ 1 条 P0/P1
不通过：某维度覆盖率为 0 → 回到第二步（问题识别）补充收集

### 4. 去重复检

随机抽查 20% 的问题对，确认没有语义重复。

通过：重复率 < 5%
不通过：≥ 5% → 回到第三步（去重环节）重新执行

## 迭代规则

| 验证结果 | 处理动作 |
|---------|---------|
| 某维度覆盖率为 0 | 回到第二步，针对该维度补充问题收集 |
| 用户满意度 < 70% | 分析不满意的维度，回到第五步优化问题表述 |
| 专家评分 < 4 分 | 请专家指出具体问题，回到第四步修正标准 |
| 重复率 ≥ 5% | 回到第三步重新执行 |

## 迭代周期

- **小版本迭代**：每两周执行一次验证，更新问题清单
- **大版本迭代**：每季度重新执行完整流程（第一步到第八步）
- **主题变更**：立即触发完整流程重跑
