# gin-problem-clarify：问题定义与澄清

把模糊主题转化为可执行的结构化问题清单。本技能执行 8 步修订方法论，每个步骤都有 Progress 状态标签。

> 当前版本：v0.1.0（2026-08-30）· 变更记录见技能目录「更新日志.md」

## 适用场景

- 想做一份教程，先明确该教程要回答哪些问题
- 想做内容选题，整理一份主题下最值得回答的问题清单
- 想做市场调研，先梳理用户最关心的真问题
- 想做深度研究，定义清楚要研究的子问题清单
- 想把领域知识结构化，先以问题为骨架

## 不适用

- 已有清晰问题，直接回答 → 走深度研究/问答类技能
- 纯创意发散 → 走头脑风暴类技能
- 仅生成答案不梳理问题 → 走写作类技能

## 运行流程（8 步）

```
输入主题 → 领域拆解 → 问题识别 → 去重与合并 → 问题判定 → 问题澄清 → 分层与排序 → 输出清单 → 验证迭代
```

| 步骤 | 产出 | 是否新增 |
|------|------|---------|
| 1. 领域拆解 | 维度标签树（MECE） | — |
| 2. 问题识别 | 原始问题池（含来源与频次） | 新增来源类型 |
| 3. 去重与合并 | 问题候选池 | **新增** |
| 4. 问题判定 | 通过/淘汰/降级判定结果 | 修订为串行关卡 |
| 5. 问题澄清 | 澄清后的精准问题表述 | 新增映射关系 |
| 6. 分层与排序 | 三维坐标 + 量化分数 | **新增** |
| 7. 输出清单 | 结构化问题清单 | 主+副类型分类 |
| 8. 验证迭代 | 验证报告 + 迭代计划 | **新增** |

## 进度展示

执行时按以下 micro-checklist 推进，状态用 `[自动]/[需确认]/[硬闸门]` 标注。

```markdown
Progress:
- [ ] Step 1 领域拆解：建立 7 个 MECE 维度标签 `[自动]`
- [ ] Step 2 问题识别：收集原始问题池（频次 ≥ 2）`[自动]`
- [ ] Step 3 去重与合并：dedupe_questions.py `[自动]`
- [ ] Step 4 问题判定：judge_questions.py 四关串行 `[自动]`
- [ ] Step 5 问题澄清：填写五要素 `[需确认]` ← 当前
- [ ] Step 6 分层排序：rank_questions.py 计算 P0/P1/P2 `[自动]`
- [ ] Step 7 输出清单：写入结构化字段 `[自动]`
- [ ] Step 8 验证迭代：覆盖率/去重/满意度检查 `[需确认]`
```

## 脚本入口

```bash
python3 scripts/dedupe_questions.py   < pool.json   > candidates.json
python3 scripts/judge_questions.py    < candidate.json
python3 scripts/rank_questions.py     < judged.json  > final.json
```

每个脚本对应 .docx 方法论中可机器化的步骤，其余步骤（领域拆解、问题澄清）由 Agent 按 `references/methodology.md` 与 `references/clarification-form.md` 引导用户完成。

## 详细规范

每个步骤的判定规则、淘汰标准、边界示例、产出字段：

- `references/methodology.md` — 完整方法论 8 步
- `references/clarification-form.md` — 第五步五要素填写模板
- `references/output-schema.md` — 第七步结构化清单字段定义
- `references/verification-checklist.md` — 第八步验证迭代清单

## 边界

- **不写答案**：本技能只梳理问题，不生成答案。生成答案请走 `针对一个问题找答案/` 类技能。
- **不写教程**：本技能只梳理问题，不写教程正文。写作请走 `教程写作/` 类技能。
- **不深度调研**：本技能只识别问题与频次，不做联网深度调研。深度研究请走 `找问题/`、`针对一个问题找答案/` 类技能。
- **路线规划**：本技能的产出是后续工作的「输入」。建议组合：教程选题 → 本技能生成问题清单 → 教程写作技能按 P0 问题逐题展开。

## 触发词

- 「我想做一个 XX 教程，帮我梳理要回答哪些问题」
- 「关于 XX 主题，用户最关心的问题是什么」
- 「帮我整理一份 XX 主题的问题清单」
- 「研究 XX 领域，先把问题列出来」
- 「内容选题 / 选题方向 / 问题清单」
- 「XX 主题应该写哪些内容」
- 「skill-creator / 做教程 / 写选题」相关场景

## 不触发

- 「帮我回答这个问题」→ 走答案生成类技能
- 「头脑风暴 / 创意发散」→ 走 brainstorming 类技能
- 「直接写一篇文章」→ 走写作类技能
