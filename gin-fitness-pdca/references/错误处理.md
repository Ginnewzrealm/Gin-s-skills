# 错误处理

> 任何子技能出错时，由 pdca-report 统一按本文件处理。

## 错误分类

| 错误类型 | 说明 | 处理策略 |
|----------|------|---------|
| 网络错误 | lark-cli 超时、连接失败 | 重试3次，指数退避 |
| 权限错误 | 无访问权限（错误码99991663）| 终止，提示检查 spreadsheet 分享权限 |
| 参数错误 | 表格/子表/字段不存在 | 终止，提示检查配置 |
| 限频错误 | API限频 | 等待5秒后重试，最多3次 |
| 数据错误 | 字段值为空、格式错误 | 跳过，记录日志 |

## 终止条件（立即终止，不得继续）

1. config.json 不存在或 initialized ≠ true（且用户拒绝初始化）
2. 日期字段无法读取
3. 权限不足（错误码 99991663）
4. 表格或子表不存在（`+workbook-info` 返回缺失）
5. 写入确认失败（重试3次后仍无法读取回执）

## 错误码映射（Sheets 后端）

| 错误码 | 含义 | 关键处理 |
|--------|------|---------|
| `CONFIG_MISSING` | 配置缺失 | 提示运行初始化流程 |
| `TABLE_NOT_FOUND` | spreadsheet 不存在，或 `daily_sheet_name` / `pdca_sheet_name` 子表不存在 | 提示检查 URL 和子表名 |
| `RECORD_NOT_FOUND` | 日期行/周号行不存在 | 需要时由本技能自动创建，不直接报错 |
| `LARK_SKILL_UNAVAILABLE` | 所选后端依赖的 `lark-sheets` skill 未安装或不可用 | 检查是否已安装 lark-sheets skill |
| `FIELD_TYPE_MISMATCH` | 字段元数据中的类型/选项与真实表格列验证不一致 | 返回 warning，提示用户检查表格字段配置；不阻塞其他字段写入 |
| `FIELD_NOT_FOUND` | 写入请求包含表头行中不存在的字段名 | 停止该字段写入；字段名必须来自运行时读取的表头行 |
| `FIELD_WRITE_FAILED` | 字段写入后回读不一致 | 换工具重试后仍失败，不阻塞其他字段 |
| `INVALID_OPTION` | 选项无效 | 给出可选值列表，请用户重选；一律禁止新建选项 |

## 错误通知

终止或阻断后调用 pdca-notify 发送错误通知（格式见 pdca-notify 的话术模板）。
cron 无人值守场景下，错误通知是唯一告知渠道，必须发送。
