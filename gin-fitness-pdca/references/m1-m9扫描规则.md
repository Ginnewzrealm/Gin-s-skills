# M1-M9 代谢扫描规则

> pdca-diagnosis 执行扫描前必须读取本文件。所有「有问题」判定标准为持续（≥3天）。

## M1：水分潴留

**字段来源（动态映射）：** 睡前体重、次日晨起体重、排便状态

```
昼夜体重差值(kg) = 前一晚睡前体重 - 当日晨起体重
```

阈值（大解状态 = 今日1次，非便秘日）：正常 0.6–1.1kg（含1.1）；有问题 >1.1kg
阈值（大解状态 = 无/量少，便秘日）：正常 0.7–1.3kg（含1.3）；有问题 >1.3kg

**触发条件：** 昼夜差值持续（≥3天）超出正常上限

## M2：热量缺口失效

**字段来源：** 晨起体重

```
本周晨起体重均值 = Σ(本周7天晨起体重) / 7
上期晨起体重均值 = Σ(上期7天晨起体重) / 7
周变化(kg) = 本周均值 - 上期均值
```

**阈值（必须查阅知识库 `knowledge/减脂速度评估与调整频率指南.md` 第一~三节获取当期有效口径，禁止凭记忆使用旧数字）：**
- 正常：周变化处于知识库定义的安全减脂速度区间（按当周实际体重换算）
- 有问题：连续两期体重变化低于安全区间下限（趋势性停滞），或主动降热量后体重反升
- 周下降超过安全区间上限为「过快」，同样标记为有问题（肌肉流失风险），并在 evidence 中注明「过快」

**触发条件：** 连续两期体重偏离安全速度区间，或降热量后反升

## M3：夜间皮质醇偏高

**字段来源：** 入睡难度、半夜醒来、早起状态。三项联合，取最严重项。

| 入睡难度 | 判断 |
|----------|------|
| 正常（<15分钟） | 正常 |
| 轻度异常（15-30分钟） | 有问题 |
| 明显异常（>30分钟） | 有问题 |

| 半夜醒来 | 判断 |
|----------|------|
| 没有醒来 | 正常 |
| 醒来一次/轻度异常 | 有问题 |
| 明显异常 | 有问题 |

| 早起状态 | 判断 |
|----------|------|
| 神清气爽/良好/正常 | 正常 |
| 疲惫/非常疲惫 | 有问题 |

**触发条件：** 三项中任一项持续（≥3天）处于「有问题」状态

## M4：交感神经兴奋

**字段来源：** 晨起心率

```
心率偏移 = 当日晨起静息心率 - 近7天基础心率均值
```

基础心率必须来自平稳状态日（无训练日/无压力日/无疾病日，剔除异常标记日）。

- 正常：偏移 < 3次/分
- 有问题：偏移 ≥ 3次/分

**触发条件：** 心率偏移持续（≥3天）≥ 3次/分

## M5：皮质醇节律紊乱

**字段来源：** 傍晚情绪

- 正常：情绪平稳
- 有问题：偶尔紧绷 或 频繁焦虑

**触发条件：** 傍晚情绪持续（≥3天）不是「情绪平稳」

## M6：血糖波动/胰岛素异常

**字段来源：** 午餐时间、午餐饥饿时间、午餐饥饿程度、午餐饥饿速度

```
餐后小时数 = 午餐饥饿时间 - 午餐时间
```

**正常判定（AND 联合条件，必须同时满足）：**
1. 餐后小时数在 3.5–4 小时（含边界）
2. 饥饿程度 ≤ 6
3. 饥饿速度 = 逐渐

**有问题判定：**
- 有问题：餐后 ≤3 小时，或程度 ≥7，或速度 = 突然
- 严重有问题：餐后 ≤2.5 小时 且（程度 ≥7 或 速度 = 突然）

**触发条件：** 餐后饥饿时间持续（≥3天）处于「有问题」状态

## M7：瘦素敏感性下降

**字段来源：** 碳水渴望（0-4分文本）

- 正常：0分 或 1分
- 有问题：2分（偏好吃甜食/面食）/ 3分（很想吃）/ 4分（停不下来）

**触发条件：** 碳水渴望持续（≥3天）处于3分以上

## M8：脂肪分解被抑制（组合指标，不是独立判断）

**触发条件：** M6、M7、M2 三项中任意二项同时「有问题」

| M2 | M6 | M7 | M8 状态 | 推断 |
|----|----|----|---------|------|
| 正常 | 正常 | 正常 | 正常 | 三项均无异常 |
| 有问题 | 有问题 | 正常 | 有问题 | 热量缺口存在但体重不动，脂肪分解可能被抑制 |
| 有问题 | 正常 | 有问题 | 有问题 | 能量储备感知不足 + 体重不动，脂肪分解可能被抑制 |
| 正常 | 有问题 | 有问题 | 有问题 | 血糖波动 + 碳水渴望，脂肪分解可能被抑制 |
| 有问题 | 有问题 | 有问题 | 有问题 | 三项同时异常，最严重代谢抑制信号 |
| 其他组合 | — | — | 正常 | 未触发（只有一项有问题） |

## M9：便秘/肠道功能障碍

**字段来源：** 排便状态

- 正常：今日1次
- 有问题：今日无/量少，或连续多日异常

**触发条件：** 大解状态持续（≥3天）不是「今日1次」
