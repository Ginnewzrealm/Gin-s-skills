# 输出表结构

> pdca-write 写入前读取本文件核对字段。

## PDCA周表（共12列：3标识列 + 9内容列）

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 周号 | 文本 | 格式 `YYYY-WXX`，由算法确定，禁止手填 |
| 起始日期 | 日期 | 本周起始日（周日），格式 `YYYY-MM-DD` |
| 结束日期 | 日期 | 本周结束日（周六），格式 `YYYY-MM-DD` |
| 本期闭环总结 | 文本 | 报告开头，本期整体情况速读 |
| 一、现状与目标 | 文本 | 目标差距量化，本期变化 |
| 二、减脂阶段性分析 | 文本 | 三轴判断结果（缺轴时为两轴并注明） |
| 三、做得好的 | 文本 | 含依据和标准化建议 |
| 四、存在的问题 | 文本 | 含假设验证路径和行动 |
| 五、上周行动效果 | 文本 | 执行情况和效果评级 |
| 六、下周行动 | 文本 | Why/What/When/How |
| 七、数据质量 | 文本 | 覆盖率和异常说明 |
| 八、遗留传递 | 文本 | 未闭环问题的完整历史传承 |

## CellValue 写入格式

| 字段类型 | 写入格式 |
|---------|---------|
| 文本 | "普通文本" |
| 数字 | 72.4 |
| 日期 | `"2026-08-26"`（YYYY-MM-DD） |
| 单选 | "选项名" |
| 多选 | ["选项1", "选项2"] |
| 复选框 | true / false |
