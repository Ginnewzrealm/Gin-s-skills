# 单元剧设计知识库（闭环·递进·节奏，v1.0）

本文件规定每个单元（珍珠）与单元序列（项链）的设计标准。与另外三份知识库分工：**hook_design.md 管钩子、onion_narrative.md 管真相分层与衔接、golden_chapters.md 管开篇三章、本文件管单元自身闭环与全书节奏**。重叠概念一律交叉引用，不重复定义。

一句话本质：**用"独立的闭环"给读者即时满足，用"贯穿的主线"给读者长期期待，用"递进的节奏"让读者永远觉得下一个单元更好。**

---

## 一、单元闭环的"四个必须"（硬性门槛）

一个合格单元必须同时满足：

1. **必须有独立的戏剧问题**：开头提出一个本单元专属的核心问题（如"凶手是谁"），结尾必须回答它，**禁止拖到下一单元回答**。
2. **必须有情感闭环**：不只事件解决，主角或关键配角的情感必须有落点（如受害者家属从仇恨到释然）。
3. **必须有代价**：禁止轻轻松松解决。代价形式：失去某人 / 暴露秘密 / 身体受伤 / 信任被辜负。（对应剧集总表「人物代价」列。）
4. **必须有余韵**：闭环后留一个小尾巴——意味深长的画面、耐人寻味的台词、指向主线的暗示。余韵即通往下一单元的桥。（对应「结尾钩子」，质检走 hook_design.md。）

补充原则：**闭环不能太"干净"**——事件闭环，但情感或主线留口子。

---

## 二、单元递进原则（序列不并列）

- **难度递进**：单元序列是"小怪 → 中怪 → 大怪 → BOSS"，不是案件 A→B→C 平铺。每个单元的赌注（stakes）必须比上一个更大。
- **成长三账**：每个单元结束后，主角的能力 / 情感 / 认知三本账至少变动一本，记入「状态更新」或「人物代价」。
- **自给自足**：只看任意一个单元的读者也能获得完整体验（开端/冲突/高潮/结局），同时结尾留下通往下一单元或主线的钩子。

---

## 三、主线投放的量化规则

- **主线是暗线**：每单元主线信息只露 10–20%，读者日常追的是单元明线。
- **每单元至少推进主线 5–10%**——与主线完全脱节的单元即"番外"，判 Fail。
- **均匀滴灌**：禁止前几单元零主线信息、后面集中爆发；主线线索按单元均匀分配。
- 「主线浓度」字段的量化锚点：**低** = 仅氛围暗示（<5%）；**中** = 实质推进 5–10%；**高** = 剥层节点或认知刷新（>10%，且须满足 onion_narrative.md 的"刷新人物理解"）。

---

## 四、串联机制五型（设计前声明选型）

| 类型 | 机制 | 适用 |
|---|---|---|
| 时间轴 | 按时间推进，每单元是一段经历 | 成长文、年代文 |
| 事件链 | 上单元结尾直接触发下单元开端 | 悬疑、冒险（本技能默认） |
| 主题 | 每单元探讨同一大主题的不同侧面 | 文学性作品 |
| 人物 | 每单元引入新角色，最终汇聚主线 | 群像、江湖文 |
| 空间 | 每到新地方开启新单元 | 游记式、无限流 |

- 默认**事件链**；选型须在阶段 1 步骤三开头声明，可主辅搭配（如事件链为主＋人物为辅）。
- 事件链选型下，衔接规则与"断针检查"执行 onion_narrative.md 第三节顶针规则。

## 五、节奏曲线设计（防"平"）

- **情绪波浪线**：铺垫（低）→ 小高潮（中上）→ 大高潮（满）→ 回落喘息（低）→ 全书高潮（最高）→ 余韵收束（中）。
- **大小交替**：大单元（高潮、主线推进）与小单元（日常、感情、搞笑）交替出现。
- **张弛有度**：连续两个高强度单元后，必须插入一个"喘息"单元。
- **逐步升级**：配合第二节的难度递进，赌注只增不减（喘息单元靠情感深度而非降赌注过渡）。

---

## 六、单元内部结构（三幕简化版）

单元事件（起因→经过→结果）按简化三幕展开：

- **开局（钩子）**：第一页就抛反常事件或悬念，禁止慢热铺垫——什么事件打破主角日常？
- **发展（升级）**：尝试→阻碍→反转，冲突层层升级（起承转合的"转"要爆）。
- **闭环（高潮+收束）**：怎么解决？付出什么代价？获得什么？

单元长度弹性条款：按体量自适应——网文长篇单个单元建议 3–8 万字；短剧/短篇按集计，一集一闭环或一案跨 2–3 集，以"读者不忘主线"为上界。

---

## 七、单元审计清单（并入质量审计关卡执行）

```
【闭环四必须】
[ ] 独立戏剧问题：本单元提问、本单元回答？
[ ] 情感闭环：主角或关键配角情感有落点？
[ ] 代价：非轻松解决，代价形式明确？
[ ] 余韵：闭环后留有通往下一单元/主线的尾巴？

【递进与投放】
[ ] 本单元赌注大于上一单元？
[ ] 成长三账（能力/情感/认知）至少变动一本？
[ ] 主线推进 ≥ 5%（非番外）？主线浓度档位与量化锚点匹配？
[ ] 连续高强度单元 ≤ 2 个（之后有喘息单元）？
判定：Pass / Fail（Fail 项重写后重测）
```

---

## 八、常见雷区黑名单（直接判 Fail）

1. 单元与主线脱节，写成"番外"；
2. 单元之间无递进，难度/规模/情感深度雷同；
3. 闭环太干净，无任何余韵与口子；
4. 开局太慢，前几章纯铺垫无钩子；
5. 单元过长，读者忘记主线；
6. 主线信息投放前松后紧、集中爆发。
