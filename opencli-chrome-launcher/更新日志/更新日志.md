# 更新日志

## v1.0.0（2026-09-01）

**OpenCLI Chrome Launcher 初版**

- 新增 check / init / use / cleanup 四种独立模式
- 自动检测 Chrome profile 与 OpenCLI profile 绑定，生成 `config/binding.json`
- 支持 Chrome 未运行时启动、错误 profile 时强制退出并重启
- use 模式前置 cleanup，防止 "OpenCLI Browser" 标签分组累积
- cleanup 模式先释放 OpenCLI browser session，再两阶段清理残留窗口
- 增加文件锁，防止多 Agent 并发操作 Chrome
- 输出统一 JSON 结构，方便下游 OpenCLI 技能调用
