# 动作排序规则（训练计划的执行顺序）

> 何时读我：制定训练计划排执行顺序、设定/取消弱项时，必须先读本文件。
> 本文件是动作排序的唯一真源。生成训练计划时必须按本文件排序并自检。
> 原理依据：Schoenfeld  hypertrophy 研究——在训练课前半段训练的肌肉获得更大增长；疲劳积累会损害后续动作的表现。

## 1. 排序铁律

按此顺序输出「今日动作清单」，禁止乱序：

1. **三大项永远排第 1 位**——神经负荷最大，必须在体力最充沛时做
2. **复合动作其次**——同类内按负荷从大到小；自由重量（杠铃/哑铃）排在固定器械之前（自由重量协调需求更高）
3. **孤立动作最后**——按目标肌肉从大到小
4. **核心腹部类永远垫底**——核心预先疲劳会破坏主项稳定性，任何部位日都放最后

一句话：**越重、越复杂、越多关节参与的动作越靠前，禁止"先小后大"。**

## 1b. 肌肉隔离条款（硬规则，违反即 bug）

**目标肌肉相同或 frontmatter `目标部位` 标签相同的两个动作不得相邻**，中间至少隔 1 个练其他肌肉/其他角度的动作——同一块肌肉或同一个细分角度被连续轰炸没有缓冲，影响动作质量。

- 判定粒度：
  - **目标肌肉**（如三角肌中束、胸大肌上束、肱二头肌）
  - **frontmatter 目标部位标签**（如「臀部上缘」「胸部中缝」）——当两个动作 frontmatter 都标了同一个目标部位标签时，即使主要目标肌肉不同，也尽量不相邻
  - 旧文档无 frontmatter `目标部位` 字段时，回退读取正文「一、目标肌肉（三）目标部位」小节或主要目标肌肉
- 与排序铁律的裁决顺序：先按铁律排出初稿，再检查同肌肉/同目标部位相邻；发现相邻 → 把后一个动作向后移动，插入其他肌肉/角度动作之后，**动孤立不主动作**（三大项/主项位置不动）
- 实在排不开（动作少、角度集中）→ 在计划「今日提醒」中如实说明"XX 与 XX 同练中束/同标臀部上缘，中间无法隔开，重量适当保守"，禁止装作没看见

## 2. 例外条款：弱项优先

一般规则"大肌群在前、小肌群在后"有一个例外：**用户设定的弱项（优先肌肉）**。

弱项肌肉享受三个优先：

| 优先 | 内容 |
|------|------|
| 顺序优先 | 弱项动作排进课前半段（小肌群弱项可排到大肌群孤立动作之前） |
| 训练量优先 | 弱项动作可在建议组数上 +1 组 |
| 孤立占比优先 | 可为弱项额外增加 1 个孤立动作，从更多角度刺激 |

**裁决顺序（冲突时按此裁定）**：

1. 三大项第 1 位 = 铁律，不可被弱项规则覆盖
2. 弱项前移不能排进热身，也不能排在当日三大项之前
3. 核心腹部日是弱项时：核心动作可前移至主项之后，但仍不排第 1 位
4. 未设定弱项（侧重点文件无加强行）→ 全部按铁律执行
5. 加强行是一级分类 → 该部位动作前移；是细分对象（肌肉名/目标部位标签）→ 主要目标肌肉或目标部位标签命中该对象的动作前移

## 3. 弱项的设定与存储

- 存储：知识库根目录 `训练侧重点.md`「二、部位策略」的 `加强` 行（v1.22.0 起；v1.20.0 时为「一、部位侧重点」；原 `_skill-config.json` 的 `priority_muscles` 字段已废弃，迁移规则见 kb-structure.md）
- 设定方式：用户对话——"帮我设定弱项是肩"、"我想重点练背"、"取消弱项" → 按 `references/training-focus.md` 格式写入侧重点文件并确认反馈
- 生成计划时：读取侧重点文件的加强行；无加强行则跳过弱项规则

## 4. 原理注脚

| 原理 | 对排序的含义 |
|------|--------------|
| 课前半段训练的肌肉增长更多（Schoenfeld） | 重要的、想发展的肌肉往前排 |
| 疲劳积累损害后续动作表现 | 大负荷动作趁体力充沛先做；每往后一位，预期可用重量递减 |
| 复合动作在前可为后续孤立动作预热关节 | 如：推举类先做可为臂屈伸预热肘关节，主项本身即热身 |
| 错误顺序 = 优先肌肉在疲劳状态下训练 | 弱项放课尾 = 用最差的体力练最想进步的部位 |

## 5. 反面清单（禁止出现的排序）

1. ❌ 孤立动作力竭后再做三大项/主项（体力被小动作掏空）
2. ❌ 弱项肌肉排在课尾（与训练目标背道而驰）
3. ❌ 核心腹部先练，再做深蹲硬拉（主项稳定性被破坏）
4. ❌ 固定器械排在自由重量之前且负荷倒挂（协调需求高的动作应趁新鲜做）
5. ❌ 同目标肌肉动作相邻，或同 frontmatter `目标部位` 标签动作相邻（如哑铃肩上推举接侧平举，中束被连续轰炸；两个「臀部上缘」动作连排）

**高级训练技术例外**：用户显式选用「预疲劳法」等改变顺序的高级框架时，允许孤立动作前置，但计划中必须声明"预疲劳框架，顺序有意为之"（裁决表见 `references/techniques.md` 第五节）；组合技术（超级组/复合组）不改变主体顺序，组合内两动作视为一个执行单元，位置按其中更重的动作定。

## 6. 输出前自检清单

生成计划后、发给用户前，逐项核对：

1. 三大项在第 1 位？
2. 复合动作是否全部在孤立动作之前？
3. 自由重量是否在固定器械之前？
4. 核心腹部类是否垫底？
5. 设定了弱项时：弱项动作是否在课前半段、未与三大项铁律冲突、训练量是否体现优先？
6. 启用预疲劳等改变顺序的高级框架时：是否经用户显式确认、并在计划中声明"顺序有意为之"？
7. **肌肉隔离**：同目标肌肉或同 frontmatter `目标部位` 标签的动作是否都不相邻（复合+孤立同肌肉/同标签也算）？排不开的是否已在「今日提醒」如实说明？

任一不满足 → 重排后再输出，禁止带着错误顺序发给用户。
