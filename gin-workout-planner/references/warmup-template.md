# 热身动作文档：简化模板与填写说明

> 用户添加热身动作时使用本模板。热身是动作库的平等分类之一（9 个一级分类之一），保存在 `01-训练动作库/热身/`，与其他分类同一张索引、同一套状态管理，仅文档模板为简化版；索引中热身按肌肉部位分二级。

## 为什么热身模板与训练动作模板不同

训练动作模板中的 RM 负荷、组数次数、动作原理、分重量级别的呼吸法，对热身动作都不适用。热身动作的核心是：**适用哪个训练日、做什么、做多久、做到什么程度**。

## 目标模板

文件保存为：`01-训练动作库/热身/{动作名称}.md`

```markdown
---
动作类型: 热身
适用部位: [胸部/背部/肩臂部/臀腿部/核心腹部，可多选，用顿号分隔，如：胸部、肩臂部]
器械状态: [激活/冷冻]
---

## 动作目的
[激活哪些肌肉/关节，为什么练该部位前要做它]

## 动作过程
**准备姿势**：[...]
**执行步骤**：
1. [...]
2. [...]

## 时长/次数
[如：30秒×2组 / 每侧15次×2组]

## 强度控制
[如：微微发热、关节活动开即可，不产生疲劳感]

## 注意事项
[...]
```

## 填写规则

| 字段 | 规则 |
|------|------|
| 动作类型 | 固定填 `热身` |
| 适用部位 | 从内容语义提取（如"肩环绕"→肩臂部、胸部）；可多个；语义不明确 → 问用户 |
| 器械状态 | 新建默认 `激活`；后续以动作索引.md 为准维护（比如弹力带丢了，说一声"冷冻弹力带肩环绕"即可） |
| 时长/次数 | 原文有则提取；没有 → 填 待补充，禁止编造 |
| 强度控制 | 核心原则：热身到微微发热即可，绝不能产生疲劳、影响正式训练 |

## 与训练计划流程的衔接

- 写入动作索引时，行格式（默认不勾=激活）：`- [ ] [动作名](./热身/动作名.md) ｜ 热身（适用部位） ｜ -`
- 生成训练计划时：优先读索引「热身 → 今日部位」二级标题下的未勾选动作；适用多个部位的热身以类型段「热身（适用部位）」兜底匹配，选 2-3 个填入计划的「一、热身建议」

## 完整示例

```markdown
---
动作类型: 热身
适用部位: 胸部、肩臂部
器械状态: 激活
---

## 动作目的
活动肩关节囊、激活肩袖肌群与胸大肌，提高卧推类动作前肩关节的活动度和稳定性，降低肩部撞击风险。

## 动作过程
**准备姿势**：站姿，双脚与肩同宽，双手握住弹力带两端，握距宽于肩。
**执行步骤**：
1. 双臂前平举，保持手臂伸直
2. 缓慢将弹力带从体前绕过头顶至体后
3. 控制速度原路返回至体前

## 时长/次数
每侧往返 10 次 × 2 组

## 强度控制
肩部微微发热、活动开即可；如有卡顿感，加大握距，不要强行通过

## 注意事项
全程保持手臂伸直但不要锁死肘关节；肩部有急性疼痛时禁止做该动作
```
