# 训练动作文档写作指南（内容质量约定）

> 何时读我：用户说"更新动作库""添加动作""录入新动作"（通常附带教程链接或文字）时，**必须先读本文件再动笔**，并与 `action-doc-template.md`（结构模板）配套使用。动作命名、部位/器械归类、类型判定、计重方式一律以 `rules.md` 为准；同名判定以 `name-matching.md` 为准；动作细节技术的融入方式以 `references/techniques.md` 第二节为准。

1. 工作流程（场景四）
2. 总则（五条）
3. 分字段约定
4. 边界情况处理
5. 常见错误示例

## 1. 工作流程（场景四）

### 场景进度

当前场景：健身助手 — 动作库更新

Progress:
- [ ] Step 1 接收动作教程/文字来源 [自动]
- [ ] Step 2 解析动作信息（名称/器械/目标肌肉/动作过程） [自动]
- [ ] Step 3 同名判定：是否已存在同名动作 [自动]
- [ ] Step 4 按模板撰写动作文档 [自动]
- [ ] Step 5 技术融入与分类计重 [自动]
- [ ] Step 6 格式预检与分级审稿 [需确认]  ← 当前
- [ ] Step 7 写入动作库并更新索引 [硬闸门]

进入 Step 7 前必须输出：`当前阻塞：等待你确认写入动作库。你可以回复"确认/OK/继续"，或回复"修改/重来"回退。`

禁止：
- 不要跳过用户确认直接写入动作库
- 不要在没有同名判定的情况下覆盖已有动作

1. **读取内容**：读取用户提供的链接/文字，**优先使用 OpenCli，失败后回退普通 fetch**
   - 仅文字：直接处理，不触发 OpenCli 检查
   - 含链接：按以下子流程处理——
     1. 检查 OpenCli 是否可用：执行 `opencli --version`；返回版本号 → 可用；命令不存在或报错 → 不可用，记录原因
     2. OpenCli 可用时尝试读取链接：先查站点适配器 → 优先用 `opencli <site> read <url> -f plain` → 无适配器或失败则用 `opencli browser extract <url>` 兜底
     3. OpenCli 不可用或读取失败 → 回退到 WebFetch / 普通 fetch，并一句话告知用户
2. **判断动作类型**：训练动作 or 热身动作（用户说明或内容语义；判断不了 → 问用户）；**热身动作改用 `warmup-template.md` 简化模板**，以下流程不再适用
3. **同名判定**：按 `name-matching.md` 判断动作索引中是否已有该动作——**已存在** → 走第 10 步多源择优更新；**不存在** → 走新建；**不确定** → 列出候选请用户确认，禁止猜
4. **信息提取**：通读内容，按模板各字段定位相关素材
5. **按写作指南成文**：严格按 `action-doc-template.md` 模板结构、本指南第 2-3 节约定输出，不多不少。**无论素材来源是链接、粘贴文本还是现成 Markdown 文件，一律按模板重新成文——素材载体 ≠ 产物，源文件长得再像成品也只是素材，禁止直接复制源文件充当成文**
6. **技术融入**：按 `techniques.md` 第二节适配表，为该动作选 1-3 个最适配的动作细节技术，融入「动作速度」的描述句（融入描述，不列清单；不同动作配不同技术）
7. **分类（两级）**：按 `rules.md` 第 2 节关键词映射，先定部位（一级文件夹）、再定器械（索引二级标题）；无法从名称推断 → 问用户
8. **计重方式**：按 `rules.md` 第 7 节判定（哑铃双手/龙门架双侧→单侧×2；单臂→单臂×1；杠铃/器械/自重→总重），写入 frontmatter；推断不了 → 问用户，禁止猜
9. **状态**：新建动作默认「激活」、「训练阶段」默认「学习期」，写入后告知用户可随时说"冷冻XX"、"卧推进渐进期了"调整
10. **多源择优（三阶法）**：库里已有该动作文档、或用户多次提供同一动作的资料时执行——见下
11. **格式预检（硬门控，禁止跳过）**：草稿进入审稿前必须全量自检——frontmatter 七个必填字段齐全（动作类型/器械状态/计重方式/训练阶段/最后练习/累计训练次数/估算1RM）且取值合规（无 `[...]` 占位符残留、`待记录` 不带括号、`训练阶段` 三值之一）、frontmatter 位于文件开头且其后紧跟 H1 动作名标题（**H1 与文件名一字不差**）、正文骨架章节齐全（含动作原理四小节、动作过程三阶段、新建文档的「目标部位」与「发力感知提示」小节——早于 v1.22.0 的旧文档无目标部位小节、早于 v1.24.0 的旧文档无 H1 与发力感知提示小节，均不算不合格）；任一不合格 → 打回第 5 步重写，**禁止带着格式问题进审稿、更禁止直接写入**
12. **分级审稿（硬门槛，禁止跳过）**：审稿对象是「待写入知识库的文档」，与内容来源无关（现成 Markdown 文件同样要审）——
    - **单篇入库**：草稿完整发到聊天，用户明确确认后才允许执行第 13 步写入
    - **批量建库**（用户一次提供多份资料或明说批量入库）：按部位分批处理，每批输出「批次清单」（动作名 / 类型 / 器械归位 / 计重方式 / frontmatter 合规✅ / 内容摘要一行），用户审清单、可点名看全文，确认后整批写入
    - **多源择优更新已有文档**：逐篇完整审（覆盖存量内容，风险最高，不打包）
    - 禁止未审先写、禁止"边写边告知"
13. **写入 + 更新索引**：写入对应部位文件夹，并在动作索引.md 对应「部位 + 器械」二级标题下加行，两处同步，禁止只改一处；写完按 `kb-structure.md`「行排序规则与巡检」自检全表排序

输入可能是：URL 链接 / 一段文字 / 文件名 + 链接或文字 / 用户上传的现成 Markdown 文件（同样只是素材，不是可直接入库的产物）。文件名可能含关键信息，如 `上斜杠铃卧推（rm60Kg*5）.md` → 动作名：上斜杠铃卧推。

### 多源择优（三阶法）

1. **拆解对齐**：把每篇资料按模板八个字段强制拆开对位，原文结构再乱也拆进这八个格子；资料没覆盖的字段标 `[空白]`
2. **逐字段对比**（定性判断，不打分）：对每个字段判断资料与已有文档谁更好——解剖描述更精确？参数更具体？错误/禁忌覆盖更全？逻辑更自洽？
3. **四种处置**：
   - 整篇更差 → **丢弃**不用
   - 个别字段更好 → **定点嫁接**：只替换该字段里更精确的表述，不动整体框架
   - 整篇明显更好 → **模块重写**：以它为基底重写该字段
   - 多篇各有所长 → **拼合重组**：取各自最好字段拼合
4. **逐句标注差异**：`[新增]` 资料有而已有没有的有效信息 / `[替换]` 同一信息点资料表述更精确 / `[冲突]` 相互矛盾 → 标记「待用户确认」并说明冲突点 / `[冗余]` 废话、营销话术 → 丢弃
5. **优化日志**：合并完成后输出——改了哪些字段、内容来自哪篇资料、为什么改

**素材为王不动摇**：资料没有的内容一律「待补充」，**禁止凭解剖学知识推导补全**——资料全都不行也不行。

## 2. 总则（五条）

1. **素材为王**：所有内容从用户提供的链接/文字中语义读取、提取、总结。原文没提的字段填「待补充」，**禁止凭主观经验补充任何要点**——包括安全注意事项，再"显然"也不行。**白名单例外仅两处**：①「动作原理」节的（一）肌肉附着点、（二）肌肉生理原理两小节，允许按客观解剖事实填写；②「四、动作过程」三阶段注意点与「六、动作速度」中的借力屏蔽/发力感知类提示，允许按公认训练学手段补写（只写经典公认手段——预先疲劳、握距/体位微调、降重孤立、念动一致、顶峰收缩与离心强化等；禁止生僻技巧与个性化处方）。**注意：「四、动作过程（四）发力感知提示」小节不适用白名单②**——该小节只收录真实流传的素材/检索技巧，一律按 `references/cue-collection.md` 采集，检索不到就写"未检索到"，禁止 AI 编造。两处约定详见第 3 节
2. **恰到好处**：把素材讲透为止。不许过度提炼成电报体（"推起""放下"式无信息量步骤）；也不许注水成流水账、堆砌营销话术（"炸裂""泵感爆棚"）
3. **各归其位**：速度写进「动作速度」，不写进「动作过程」；组数/次数/重量等计划参数不写进动作文档（那是训练计划的事）；与动作本身无关的科普不收录
4. **多源择优**：同一动作的多份资料按第 1 节三阶法合并，输出优化日志
5. **语言**：客观、专业的书面语，指令式写法（"双脚踩实地面"），不复制原文口语（"小伙伴们"）

## 3. 分字段约定

- **H1 动作名标题**：frontmatter 结束后紧跟 `# 动作名称`，与文件名一字不差（文件名是动作名唯一权威，H1 是展示副本；改名时两者同步改）
- **一、目标肌肉**：主肌精确到束/部（写"胸大肌上束"，不写"胸肌"）；协同肌标注参与度（主要协同/次要协同）；稳定肌不凑数罗列。**（三）目标部位**：从 rules.md 目标部位标签词表选 1~2 个日常表达标签（如"胸部中缝""胸大肌上缘"），按动作力学特征贴（内收类→中缝、上斜角度→上缘），素材无依据不贴；与主要目标肌肉同名可省略
- **二、器械选择**：推荐器械带关键规格（凳角度、握距、把手位）；替代器械注明替代后的差异（如"哑铃版活动度更大，对稳定要求更高"）；无替代写"无"
- **三、动作原理**：固定四小节，不多不少——（一）**肌肉附着点**：起点与止点（客观解剖事实，**允许 AI 按解剖学常识填写**，属素材为王的白名单例外）；（二）**肌肉生理原理**：目标肌肉向心收缩完成的关节运动（同属白名单例外）；（三）**动作力学机制**：从素材提取——阻力方向、发力阶段向心收缩克服负重、下放阶段离心收缩控制负重，素材没讲清填「待补充」；（四）**训练作用**：素材提了什么写什么，没提填「待补充」，**禁止写"通过反复抗阻刺激提升肌力与围度"这类万能套话**
- **四、动作过程（固定三阶段，编号检查点）**：（一）**准备阶段**——编号清单逐项写，固定顺序：地面接触点（脚掌/站距/脚尖方向）→ 沿动力链自下而上（膝 → 髋 → 腰腹核心 → 躯干/肩胛 → 头颈视线）→ 器械接触点（握法/握距/手腕，末项含起杠建立起始位）；卧姿/坐姿动作从支撑面接触点开始（臀 → 上背/肩胛 → 头贴凳），再收束到手臂；每项 = 身体部位 + 姿势要求 + 一句话目的，让用户做组前能从上往下过一遍身体自检。（二）**发力阶段（向心收缩）**、（三）**还原阶段（离心收缩）**——同样编号逐条写，每条 = 做什么 + 怎么做 + 注意点；顶峰收缩归发力阶段末项，收杠归还原阶段末项，**从启动到收杠完整闭环，不许省略还原**。**三阶段的注意点必须写透两件事**：①身体姿态要点（哪个部位保持什么状态）；②屏蔽辅助肌借力 + 突出目标肌发力（如"大臂贴躯干固定，不给肩部借力条件""专注目标肌持续收紧的主导感"）——素材有就提取，素材没有可按公认训练学手段补 1-2 条（白名单例外二）；与五章划界：本章只写正面要求一句话，错误的展开分析（表现/后果/纠正三要素）归「五、运动轨迹幅度」，两边不重复展开。（四）**发力感知提示**——新建文档必填小节；采集、识别、排除、输出格式一律以 `references/cue-collection.md` 为唯一真源：只收录真实流传的教练/训练者技巧（用户素材或公开教学资料检索），每条 = 类别标签【运动意象/躯体锚点】+ 操作 + 效果三件套，小节末尾固定追加统一备注；检索不到写「未检索到该动作公开流传的发力感知提示」+ 备注，禁止编造凑数
- **五、运动轨迹幅度**：标准轨迹写清形状、起点、止点和幅度依据；常见错误 2-3 个，每个写三要素——**错误表现 → 代偿肌肉/力学后果 → 纠正方法**（素材没讲机制就只写表现和纠正，不编）
- **六、动作速度**：三阶段各 1-2 句，秒数+控制要点；技术融合在此落地（按 `techniques.md` 第二节适配表选 1-3 个融入描述句：孤立小肌群优先顶峰收缩+离心控制，复合增力优先 CAT，大重量三大项顶部不写顶峰收缩）
- **七、呼吸配合**：发力/归位各一句；仅大重量复合动作补充瓦氏呼吸（深吸屏息、过粘滞点后呼出），孤立小动作不套
- **八、安全注意（四层，不混写）**：绝对禁忌症＝有该情况禁止做；相对禁忌/参数调整＝改参数才能做；高风险人群警示＝需保护或监督；辅助保护建议＝具体做法。素材没提的层保持「待补充」

## 4. 边界情况处理

| 情况 | 处理 |
|------|------|
| 原文未提及某字段 | 填 **待补充**，严禁凭空捏造 |
| 不同段落信息矛盾 | 填 **待用户确认** 并简要说明冲突点 |
| 语言风格 | 客观、专业、简洁的书面语 |
| OpenCli 检查失败（命令不存在/报错） | 记录原因，直接回退 WebFetch/普通 fetch，一句话告知用户，不中断流程 |
| 链接需登录/付费墙/反爬拦截 | 告知用户，请其粘贴正文或换链接 |
| OpenCli 读取成功但内容为空/乱码/与动作无关 | 回退 WebFetch 重试一次；仍不行 → 请用户粘贴文字 |

### 已有文档迁移规则

模板结构变更后，已有动作文档不自动批量改写。两种触发方式：

1. 该动作下次有资料更新时，按新模板重排并补齐四层安全注意（内容只迁移不新编）
2. 用户说"刷新全部动作文档格式"→ 逐个重排，每改一篇在聊天里报一篇

## 5. 常见错误示例

| 错误 | 表现 | 正确做法 |
|------|------|----------|
| 主观臆断 | 原文没提，自行补充"腰椎间盘突出者慎做"等注意事项 | 原文未提及一律填待补充 |
| 推导补全 | 资料不足时凭解剖学知识自己写 | 素材为王，缺失标待补充 |
| 过度提炼 | 三阶段步骤写成"推起""放下"，无操作要点 | 每条"做什么+怎么做+注意点" |
| 注水啰嗦 | 一句话拆三句说，塞营销话术 | 把素材讲透为止，讲透即停笔 |
| 字段交叉 | 把速度秒数写进「动作过程」步骤里 | 速度只写进「动作速度」 |
| 直接复制原文 | 大段公众号原话，带"小伙伴们"等口语 | 提炼核心逻辑，书面语概括 |
| 格式不统一 | 自增"## 训练心得"字段，或改字段名 | 100% 复刻模板标题层级、加粗、标点 |
| 命名不规范 | "哑铃推胸""上斜推" | 按 rules.md 命名规则："上斜杠铃卧推" |
| 链接读取跳过 OpenCli | 用户给链接时直接用 WebFetch，未检查 OpenCli | 优先检查并尝试 OpenCli，失败再回退 |
| 复制源文件直接入库 | 源文件是现成 Markdown → 跳过成文/预检/审稿，直接复制写入并删除源文件 | 源文件只是素材：一律走第 5 步模板成文 → 第 11 步格式预检 → 第 12 步分级审稿 → 第 13 步写入 |

## 6. 完整示例（标准文风样板）

### 输入（教程文字）

> 上斜卧推主要训练胸大肌上束，同时三角肌前束和肱三头肌也会参与发力。仰卧于上斜凳上，双脚踩实地面，肩胛骨收紧下沉贴紧凳面，核心收紧。呼气推起杠铃至手臂微屈，顶峰停顿感受收缩，吸气匀速下放。杠铃沿斜上方弧线推起。常见错误：肩胛骨未收紧，会导致肩部代偿，解决方法是全程后缩下沉挺胸。向心1-2秒，顶峰停1秒，离心2-3秒。推起呼气，下放吸气。

### 输出

（复合动作样板：向心融入 CAT、离心融入离心控制——融进描述句，不出现技术名清单）

```markdown
---
动作类型: 复合动作
器械状态: 激活
计重方式: 总重
训练阶段: 学习期
最后练习: 待记录
累计训练次数: 0
估算1RM: 待记录
---

# 上斜杠铃卧推（与文件名一字不差）

## 一、目标肌肉

### （一）主要目标肌肉
　　胸大肌上束

### （二）协同/拮抗肌肉

### （三）目标部位（日常表达标签）

## 二、器械选择

### （一）推荐器械

### （二）替代器械

## 三、动作原理

### （一）肌肉附着点
　　胸大肌起点位于锁骨内侧半、胸骨及上位肋软骨，止点附着于肱骨大结节嵴；上斜推举的发力主要对应其锁骨部（上束）。

### （二）肌肉生理原理
　　胸大肌向心收缩，完成肩关节水平内收与屈曲。

### （三）动作力学机制
　　杠铃重力构成向下阻力，上斜角度将负荷焦点从胸大肌中部移至上束。推起阶段，胸大肌上束主导肩关节水平内收、做向心收缩克服负重，三角肌前束协助，肱三头肌完成伸肘；下放阶段，上束做离心收缩控制负重，被逐渐拉长并保持张力。

### （四）训练作用
　　通过拉长与收缩的完整循环，集中刺激胸大肌上束。

## 四、动作过程

### （一）准备阶段
1. 脚掌：双脚踩实地面，全脚掌均匀受力——建立下肢稳定根基
2. 髋：臀部贴紧凳面，不悬空不侧移——固定骨盆，杜绝臀部抬离借力
3. 腰腹核心：核心收紧，躯干无多余松弛——保持全身张力一体
4. 躯干/肩胛：肩胛骨后缩下沉、贴紧凳面，挺胸——这是保护肩膀的基础，同时锁死肩部借力空间，把发力让给胸大肌
5. 头颈：头部自然贴凳，视线朝向上方——保持脊柱中立
6. 手臂握法与起杠：握距略宽于肩，杠铃落在掌根，手腕中立不后折；将杠铃推离卧推架平移到上胸正上方，肩胛保持后缩

### （二）发力阶段（向心收缩）
1. 胸部主动发力，沿斜上方弧线推起——完全依靠胸大肌上束主导收缩，杜绝耸肩抬肩借力
2. 推起过程匀速平稳，不爆发甩动——保证负重压力全程锁定目标肌
3. 推至手臂微屈即停，顶峰刻意收紧胸大肌上束——肘关节不完全锁死，防止负荷转移到肱三头肌与关节

### （三）还原阶段（离心收缩）
1. 控制杠铃沿斜下方弧线匀速落向上胸，小臂始终垂直于地面——不放任重力自由落体
2. 下放全程保持胸大肌上束张力，不松懈不脱力；躯干、肩胛姿态固定不动
3. 杠铃轻触上胸即停，不借助反弹；完成末次后先稳住杠铃，再挂回卧推架

### （四）发力感知提示
　　1. **【运动意象】** 操作：推起过程中，想象双手把杠铃向两端"掰断"
　　　　效果：激活上背部稳定，优化肩胛姿态，减少肩部代偿，让胸大肌上束更好主导发力
　　备注：发力感知提示仅作为辅助找发力感觉的手段，不属于强制动作标准，个体感受存在差异，不能替代客观动作框架。

## 五、运动轨迹幅度

### （一）标准轨迹
　　杠铃沿斜上方弧线运动，起点在上胸正上方，下放至杠铃轻触上胸。

### （二）常见错误轨迹
1. **肩胛骨未收紧**
　　（1）错误表现：肩胛骨未后缩下沉、贴紧凳面
　　（2）代偿肌肉/力学后果：肩部代偿发力，肩关节受伤风险增加
　　（3）纠正方法：全程保持肩胛骨后缩下沉，挺胸
2. **下放过深**
　　（1）错误表现：杠铃超过上胸继续下沉
　　（2）代偿肌肉/力学后果：肩前侧压力骤增
　　（3）纠正方法：杠铃触上胸即停，幅度以肩部无不适为准

## 六、动作速度

### （一）向心阶段（推起）
　　1-2秒，在可控前提下尽可能快推起，保持轨迹稳定不晃动。

### （二）顶峰收缩
　　停顿1秒，收紧胸大肌上束，肘关节不完全锁死。

### （三）离心阶段（下放）
　　2-3秒，默数节奏匀速下放，不放任重力自由落体。

## 八、安全注意

### （一）绝对禁忌症

　　肩部有旧伤或不适者减轻负荷，下放幅度以肩部无不适为准；握杠保持手腕中立，负荷落在掌根，避免腕关节受压。

### （三）高风险人群警示
　　新手应从轻重量开始，或由保护者在旁辅助。
```
