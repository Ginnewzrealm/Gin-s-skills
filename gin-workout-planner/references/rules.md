## 2. 部位分类与关键词映射

动作库共 9 个一级分类（肌肉部位）：`胸部 / 背部 / 肩臂部 / 臀腿部 / 核心腹部 / 全身功能性 / 有氧 / 拉伸筋膜 / 热身`（索引标题「核心/腹部」「全身/功能性」「拉伸/筋膜」对应文件夹名去掉斜杠）。统一一套结构、一张索引、一套状态管理（热身是平等分类，仅文档模板用简化版）。

**用户口语 → 一级分类映射**：胸→胸部；背→背部；肩/手臂/肩臂→肩臂部；臀/腿/臀腿/下肢→臀腿部；腹/腰腹/核心→核心腹部；全身/功能性→全身功能性；有氧→有氧；拉伸/筋膜放松→拉伸筋膜。

| 动作关键词 | 部位 |
|------------|------|
| 卧推、夹胸、俯卧撑、屈臂上拉 | 胸部 |
| 下拉、划船、引体、直臂下压、挺身 | 背部 |
| 推肩、推举、平举、提拉、面拉、片旋转、弯举、臂屈伸、三头下压、手腕弯举 | 肩臂部 |
| 臀冲、臀桥、后踢、髋外展、髋内收、髋铰链、蹲、腿弯举、腿屈伸、腿举、箭步蹲、腿外展、腿内收、提踵 | 臀腿部 |
| 卷腹、抬腿、平板支撑、转体 | 核心腹部 |
| 波比、战绳、农夫行走、翻站、抓举、挺举 | 全身功能性 |

### 消歧规则（冲突关键词必须按此处理）

| 关键词 | 判定 |
|--------|------|
| 飞鸟 | 平板/上斜/器械飞鸟、夹胸类 → **胸部**；俯身飞鸟、反向飞鸟、侧平举类 → **肩臂部** |
| 硬拉 | 杠铃硬拉、罗马尼亚硬拉 → **背部**（三大项）；直腿硬拉 → **臀腿部**（主练腘绳肌） |
| 平板 | 「平板支撑」类静态支撑动作 → **核心腹部**；「平板」作角度前缀时（如平板杠铃卧推）**不参与部位判定**，以动作名称关键词为准（卧推 → 胸部） |
| 支撑 | 仅与平板/侧桥等静态核心动作组合时 → **核心腹部**；器械名称中含"支撑"（如支撑架）不触发 |
| 划船 | 坐姿/俯身划船等力量动作 → **背部**；「划船机」→ **有氧** |

### 目标部位标签词表（唯一真源；动作文档 frontmatter `目标部位` 字段与正文「一、目标肌肉（三）目标部位」只从这里取词）

动作文档的「目标部位」是**日常表达标签层**，承载于 frontmatter 的 `目标部位` 字段（旧文档无该字段时回退读取正文「一、目标肌肉（三）目标部位」小节），承接"中缝/上缘"这类解剖字段装不下的口语说法；解析时与「主要目标肌肉」双通道匹配侧重点（见 training-focus.md）。标签规则：

- **只从词表选词**；词表没有的表达 → 报告用户，用户确认后扩充本表，禁止临场造词
- 每个动作贴 **1~2 个**标签，主标签在前；标签与「主要目标肌肉」同名时可省略不贴（解析已读肌肉字段）
- 贴标签必须有素材依据（按动作力学特征判定：内收类→中缝、上斜角度→上缘、俯身→后束、垂直拉→背部宽度、水平拉→背部厚度、挺身/背伸类→下背、平板支撑类→核心整体等），禁止无依据贴标签
- 全身功能性/有氧/拉伸筋膜/热身：不设目标部位标签

| 背部 | 上背、背部宽度、背部厚度、下背（竖脊肌） |

## 3. 三大项与部位主项规则

| 训练部位 | 必选三大项/主项 |
|----------|-----------|
| 胸部 | 平板杠铃卧推 |
| 背部 | 杠铃硬拉（与罗马尼亚硬拉视为同一动作） |
| 臀腿部 | 杠铃深蹲、杠铃臀冲（双主项，每次至少其一） |

- 每次练胸部/背部/臀腿部，计划必须包含对应三大项/主项。**主项与三大项同权**：当日必选、排第 1 位、组数与组间休息按三大项规格（volume-params.md）；全技能凡出现「三大项」的规则条款（排序第 1 位、负荷最重、质检检查项等），臀腿部主项（杠铃深蹲、杠铃臀冲）同等适用。
- 臀腿部设**双主项**（杠铃深蹲 + 杠铃臀冲）：每次臀腿部训练必须至少包含其中一个主项；两个主项都满足近期冲突/避开规则时，优先按当次训练侧重点选择（臀侧重 → 杠铃臀冲，腿侧重 → 杠铃深蹲）；无明确侧重时，选间隔最久的那一个。若用户选择「避开」杠铃深蹲/杠铃臀冲，则另一个主项必须保留。
- 肩臂部、核心腹部日没有三大项/主项，直接从复合动作开始编排。
- 全身/功能性、有氧、拉伸/筋膜不设三大项/主项，不参与部位日编排（入库、索引、状态管理照常适用）。
- **近期冲突例外（v1.23.0 起）**：三大项/主项动作若昨天或今天已练（以动作索引「最后练习」为准），**不自动跳过**，但必须在合并确认段声明并请用户裁决（照常 / 降量 / 换同类变式 / 改练别的部位）。硬排除权仍只属于侧重点「避开」。

## 4. 动作类型判定与负荷铁律

**组数、次数、负荷、组间休息的完整方法论以 `references/volume-params.md` 为唯一真源**（含训练目标/训练水平两个用户变量、次数区间表、单动作组数铁律、周容量参考、组间休息表、交互原则、1RM 推导、RPE、输出前自检清单），本文件不另存副本。生成训练计划前必须读取该文件并严格执行。

- 类型判定：三大项见第 3 节名单；多关节多肌群参与 = 复合动作；单关节单肌肉 = 孤立动作
- 负荷计算（铁律）：**本次重量 = 估算 1RM × 百分比**；1RM 必须用 Brzycki 公式从训记/日记历史记录反推（流程见 `references/volume-params.md` 第七节），禁止把历史工作重量直接当基数
- 无历史数据的动作：标注「新动作，建议保守重量」，禁止虚构重量

## 5. 编排规则

优先级顺序（必须按此）：

1. **三大项优先**：按当天部位选对应三大项
2. **复合动作其次**：同部位中选「最后练习日期最久」的，优先覆盖不同角度
3. **孤立动作补充**：补齐未覆盖的角度

**侧重点选材联动**（真源 `references/training-focus.md` 第 6 节）：`训练侧重点.md` 中「避开」的部位/动作**硬排除**，优先级高于三大项必选（如避开肩臂时的卧推变式），排除动作须在计划「今日提醒」声明；「少做」动作降选材优先级但**不排除**（三大项仍必选）；「多做」动作在同等条件下优先选

### 角度覆盖原则（硬规则，违反即 bug）

**本条规则的目的是覆盖一个部位的全部细分角度，而不是限制每个角度只练一个动作。**

1. **覆盖第一（无条件铁律，v1.23.0 起）**：当日部位的**全部细分角度都必须覆盖**——角度清单以本文件第 2 节「目标部位标签词表」为唯一真源（胸＝上缘/下缘/中缝/外缘/整体厚度；背＝上背/宽度/厚度/下背；臀腿部＝臀部整体/上缘/下缘/侧臀/股四头肌/腘绳肌/大腿内侧/小腿；肩臂＝前束/中束/后束/二头/三头；核心＝上腹/下腹/侧腹/核心整体），每个动作覆盖的角度以其文档 frontmatter `目标部位` 字段为准（旧文档无该字段时回退读取正文「一、目标肌肉（三）目标部位」小节或主要目标肌肉），每个角度至少 1 个动作。**不论该部位处于什么侧重点策略（加强/维持/无策略）、走哪个次数档（4-8/8-12/12-20），覆盖义务不变。**「整体厚度/臀部整体/核心整体」类整体角度由三大项/主项/复合动作天然覆盖，不额外占动作位
2. **允许同肌肉多动作**：全部角度覆盖完后仍有名额（总数 4-6 个），允许给同一肌肉加第 2 个动作——如肩臂部日二头练 2 个（哑铃弯举 + 锤式弯举）完全合理；优先「复合 + 孤立」搭配
3. **禁止未覆盖就重复**：还有角度没覆盖、却给某角度塞第 2 个动作 = 违规；某角度动作库无激活动作可覆盖时，在「今日提醒」如实说明并提示可入库补录，不算违规
4. **移除复核（v1.23.0 起）**：任何动作被移除后（避开/黑名单/少做降级/用户临时取消），必须复核其覆盖的细分角度——该角度失去唯一动作 → 优先补一个同角度替代动作；无替代可补 → 「今日提醒」显式声明"该角度今日不练"。**移除动作不是操作的终点，角度复核才是**
5. **排序配套**：同肌肉出现 2 个动作时，执行顺序必须按 `references/ordering.md`「肌肉隔离条款」隔开，不得相邻

### 选材自检清单（输出前必须逐项过）

1. 每个动作是否都来自动作索引的激活行（禁止编造动作库没有的动作）？
2. 三大项/主项是否在场（胸部/背部/臀腿部日）？侧重点「避开」动作是否已排除并声明，「少做」是否只降级未排除？三大项/主项近期冲突是否已声明并经用户裁决？
3. 细分角度是否全部覆盖（以目标部位词表为清单，每个动作覆盖角度以 frontmatter `目标部位` 字段为准；旧文档无该字段时回退正文小节或主要目标肌肉；动作库有激活动作的角度都练到了；任何策略状态下不减角度）？若有同肌肉第 2 个动作，是否发生在全部角度覆盖之后？有动作被移除时是否已做角度复核？
4. 复合动作是否按「最后练习日期最久」选取，且能说出每个动作的选择依据（间隔天数/补哪个角度）？说不出 = 没读数据，重读后再编
5. 总动作数是否 4-6 个？（该部位激活动作不足 4 个时，按实际可用数量编排并向用户说明缺口，不算违规）

任一不满足 → 修正后再进入排序环节。

### 执行顺序

完整排序规则（含三大项第 1 位、复合负荷降序、孤立居后、核心垫底、弱项优先例外、输出前自检清单）以 `references/ordering.md` 为唯一真源，本文件不再重复展开。生成训练计划前必须读取 ordering.md 并严格执行。

原理一句话：越重、越复杂、越多关节参与的动作越靠前，绝不允许"先小后大"。

角度覆盖：以本文件第 2 节「目标部位标签词表」为唯一角度清单；动作与角度的对应以该动作文档 frontmatter `目标部位` 字段为准（旧文档缺失时回退正文「一、目标肌肉（三）目标部位」小节或主要目标肌肉），同时保留该节贴标签的力学依据作为参考（平板推类→整体厚度、上斜→上缘、内收类→中缝、垂直拉→宽度、水平拉→厚度、挺身类→下背、蹲类→股四头肌/臀部整体、臀冲→臀部整体、髋铰链→腘绳肌/臀部整体等）。本文件不再另存角度副本。

其他约束：

- 每次训练总动作数 4-6 个。
- 同一中周期（4-6 周）内保持相同动作，不频繁更换。
- 换动作信号：进展停滞、出现疼痛、心理厌倦。
- 同类替代：上斜哑铃卧推 ↔ 上斜器械卧推（同角度同类型的器械互换）。

## 6. 动作状态定义

### 场景进度

当前场景：gin-workout-planner — 动作状态与阶段管理

Progress:
- [ ] Step 1 读取动作索引和目标动作文档 [自动]
- [ ] Step 2 确认变更类型（冷冻/激活/阶段切换/换健身房） [自动]
- [ ] Step 3 执行规则校验（如学习期→渐进期条件） [自动]
- [ ] Step 4 展示变更影响给用户确认 [需确认]  ← 当前
- [ ] Step 5 更新索引/文档 frontmatter [硬闸门]

进入 Step 5 前必须输出：`当前阻塞：等待你确认更新动作状态/阶段。你可以回复"确认/OK/继续"，或回复"修改/重来"回退。`

禁止：
- 不要未确认就修改动作索引
- 不要跳过阶段切换条件检查

| 状态 | 索引中的表达 | 含义 | 编排时 |
|------|--------------|------|--------|
| 激活 | 不勾 `- [ ]` | 当前可练的动作 | 可选 |
| 冷冻 | 勾选 `- [x]`（删除线） | 暂时不考虑的动作（无器械、不想练等） | 跳过 |

**动作索引.md 的复选框是状态的唯一权威来源**；动作文档 frontmatter 的 `器械状态` 是跟随副本，以索引为准同步，不一致时按索引修正（不勾=激活，勾=冷冻）。新建动作默认不勾（激活）；用户通过勾选复选框（勾掉=冷冻）或对话（"冷冻XX"）维护状态。

### 状态管理对话流程（场景五）

用户说"冷冻XX""激活XX""列出XX部位有哪些动作""换健身房了"时，读本节执行：

```
1. 用户说"列出胸部有哪些动作"（或某部位/全部）
   → 读取动作索引，按部位列出清单，标注每个动作当前状态（✅激活/❄️冷冻）
2. 用户回复哪些激活、哪些冷冻（如"史密斯机推胸冷冻，其他保持激活"）
   → 先在动作索引.md 中切换对应行的复选框（冷冻=勾选 [x]，激活=取消勾选 [ ]）
   → 再逐个把对应动作文档 frontmatter 的 器械状态 同步为与索引一致
   → 反馈变更结果：本次激活 X 个、冷冻 Y 个
```

## 7. 计重方式（重量口径真源）

**核心原则：记录值 = 用户从器械上读到的数；换算统一在计算层，禁止要求用户心算。**

### 三档判定表

| 计重方式 | 适用动作 | 记录值含义 | 计算系数 |
|----------|----------|-----------|----------|
| `总重` | 杠铃（含杆）、史密斯、固定器械、自重类 | 读数即总重 | ×1 |
| `单侧×2` | 哑铃双手动作（哑铃卧推/推肩等）、龙门架/绳索双侧动作（龙门架飞鸟等） | 读数是**一侧**的重量 | ×2 |
| `单臂×1` | 单臂动作（单臂哑铃划船等） | 读数即手持重量；左右各做已在组数中体现 | ×1 |

### 判定规则（建动作时执行）

1. 名称含"哑铃"且双手同时持握 → `单侧×2`；含"龙门架/绳索/钢线"且双手同时 → `单侧×2`
2. 名称含"单臂/单手/单侧" → `单臂×1`
3. 杠铃/史密斯/固定器械/自重 → `总重`
4. 按名称推断不了 → 问用户，禁止猜

### 使用规则（计算层统一口径）

- **容量**（跨动作可比）：一律换算总重 `容量 = 记录重量 × 系数 × 组数 × 次数`——否则哑铃动作容量系统性减半，与杠铃动作失去可比性
- **1RM 与计划负荷**（单动作自用）：保持记录口径。Brzycki 是线性公式，单侧口径算与总重口径算严格等价；单侧动作的 `估算1RM` 存单侧值（如 33.8kg/侧），计划负荷直接输出「XX kg/侧」
- 同一动作内部口径必须永远一致；口径变更（用户改习惯）→ 告知后全文换算重写该动作数据
