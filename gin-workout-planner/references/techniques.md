# 训练技术真源（techniques）

> 何时读我：制定训练计划（组合推荐扫描、技术框架询问）、用户提起高级训练技术、新建/更新动作文档（技术融入）时，必须先读本文件。
> 三类训练技术的唯一存放处：动作细节技术、组合技术、高级训练技术。其他文件引用本文件，不另存副本。

## 一、总原则与启用方式

| 技术类别 | 启用方式 | 落地位置 |
|----------|----------|----------|
| 动作细节技术 | 建/更新动作文档时按适配表融入描述 | 动作文档（准备/发力/还原三阶段） |

## 二、动作细节技术（融入动作文档）

### 融合规则

1. **不同动作配不同技术**：按下方适配表选 1-3 个最适配的融入，禁止每个文档堆全套技术
2. **融入描述，不列清单**：把技术写进对应阶段的描述句里（如"下放默数 3 秒"），禁止单独列一行"技术：顶峰收缩"
3. **融入位置**（对应动作文档模板章节）：
   - 「四、动作过程 →（一）准备阶段」← 静力组、负重牵拉
   - 「四、动作过程 →（二）发力阶段 /（三）还原阶段」← 局部肌肉训练（按技术作用阶段落入对应小节）
   - 「六、动作速度 →（一）向心阶段」← CAT、弹性训练
   - 「六、动作速度 →（二）顶峰收缩」← 顶峰收缩、恒定张力
   - 「六、动作速度 →（三）离心阶段」← 离心控制
4. 已有旧文档无需重写；新建/更新文档时按本指南补齐

### 技术速查与适配表

| 技术 | 一句话定义 | 最适配 | 避免/禁用 |
|------|-----------|--------|-----------|
| 顶峰收缩 | 顶点主动停 1-3 秒收紧目标肌 | 孤立/小肌群（二头、三头、肩） | 顶点锁死关节的动作；大重量三大项顶部 |
| 离心控制（退让组） | 下落阶段放慢 3-5 秒 | 推/拉/下肢各类，增肌期 | 每周 ≤2 个动作；关节伤；新手慎用 |
| 恒定张力 | 全程不锁死关节，消除休息点 | 孤立动作 | 大重量复合；冲击极限重量时 |
| CAT（补偿加速） | 向心阶段尽可能快但可控 | 复合推拉动作、增力目标 | 新手；关节伤；疲劳时 |
| 静力组 | 固定角度维持 10-30 秒等长收缩 | 瓶颈角度突破、活动受限 | 高血压/心脏问题；急性炎症期 |
| 局部肌肉训练 | 只做前半程或后半程 | 中高阶补薄弱角度；力竭后榨干 | 新手；关节伤；不可长期只用局部 |
| 负重牵拉 | 肌肉拉长位加负荷停顿 | 增肌瓶颈期、改善活动度 | 关节/肌腱伤；未充分热身；训练后段 |
| 弹性训练 | 利用反弹/牵张反射快速完成 | 爆发力训练 | 新手；关节韧带伤；疲劳时 |
| 强迫次数 | 力竭后搭档辅助完成 2-3 次 | —（需搭档，**不写入文档**） | 仅用户说"今天有搭档"时可在计划中推荐 |
| 诱导重复 | 力竭后借惯性/轻辅助过渡 | —（需搭档，**不写入文档**） | 同上 |

**文档融合示例（哑铃弯举，孤立小肌群）**：顶峰收缩子节写"弯举到顶点停 1-2 秒，刻意收紧二头再放下"；离心阶段子节写"下放默数 3 秒，控制不放任重力"。

## 三、组合技术（默认融入计划推荐）

### 判断规则（选材排序后自动扫描）

1. 当日清单存在**拮抗配对**（仅肩臂部日：二头+三头；腿部日：股四+腘绳）→ 推荐【拮抗超级组】：两动作中间不休息，做完一轮再按较重动作档休息
2. 当日清单存在**同肌群相邻两动作** → 可推荐【复合组】（连续不休息）；若第二个是孤立小肌群动作且在训练尾声 → 可推荐【递减组】（力竭后立即减重再做，2-3 个重量阶梯）
3. 无命中 → 不标注，按标准顺序执行
4. 每场训练推荐组合 ≤1 处；组合不改变清单主体顺序，组合内两动作视为一个执行单元，位置按其中更重的动作定

### 输出标注（计划模板「今日动作清单」下方一行）

> **今日推荐组合**：【拮抗超级组】哑铃弯举 → 绳索下压（中间不休息，一轮后休 90 秒）。不想做就直接按顺序练，没影响～

### 约束

- 预疲劳法、对比训练法**会改变动作顺序或配对结构**，不属于默认推荐，仅在用户启用高级训练技术时可用（见第五节冲突裁决）
- 递减组每周使用 ≤2-3 个动作；巨型组（3+ 动作连续）仅小肌群、每周 1-2 次，仅在用户主动要求时推荐

## 四、高级训练技术（每次制定计划时询问一次）

默认技术框架 = **标准组**（固定组数×次数×重量，参数按 volume-params.md）。每次生成训练计划前**必须询问用户一次**是否使用高级训练技术；用户选定框架后，**框架参数覆盖默认参数**（volume-params.md 的自检按框架口径执行）。

### 技术 × 目标 × 水平 适用表（A 推荐 / B 可用 / C 禁用）

> 「目标」列的取值口径（v1.20.0 起）：按**该动作的有效次数档**映射——4-8 档视同「增力」、8-12 档视同「增肌」、12-20 档视同「肌耐力」（有效次数档解析见 training-focus.md 第 4 节）；无侧重点时即全局 `training_goal`。

| 技术 | 增力 | 增肌 | 肌耐力 | 新手 | 一句话说明 |
|------|------|------|--------|------|-----------|
| 标准组（默认） | A | A | A | A | 固定参数基准组 |
| 8-12 训练法 | C | A | B | A | 3 组同重×8-12 次，增肌核心框架 |
| 金字塔组 | B | A | B | B | 重量递增次数递减（60%×12→70%×10→80%×8→85%×6） |
| 3-5 训练法 | A | B | C | C | 3-5 次×3-5 组×休 3-5 分，高频中等容量 |
| 大重量小重量都练 | A | A | C | C | 先 2-3 次×6-8 组冲力量，再 8-10 次×3-5 组增肌 |
| 递减组 | C | A | A | C | 力竭即减重续做，2-3 个重量阶梯，训练尾声用 |
| 间歇休息（Rest-Pause） | B | A | A | C | 组间仅休 15-30 秒，提密度 |
| 停息训练（Cluster） | B | A | B | C | 组内力竭→休 10-15 秒→续做，重复 2-3 轮 |
| 21 响礼炮 | C | B | A | C | 下半程 7 次+上半程 7 次+全程 7 次，小肌群 |
| 少次多组 | A | C | C | C | 2 次×10-15 组，专项突破瓶颈（**容量例外**，见第五节） |
| 对比训练法 | A | C | C | C | 大重量后立刻接爆发动作（深蹲→跳箱） |
| 预疲劳法 | C | A | B | C | 先孤立耗尽目标肌再做复合（**排序例外**，见第五节） |
| 巨型组 | C | A | B | C | 3+ 动作连续，仅小肌群，每周 1-2 次 |
| 渐降组 | C | B | A | C | 同次数连续降重，小肌群 |
| 加压训练法（BFR） | — | — | — | — | **不纳入**（无护具） |

### 启用流程

1. **每次生成训练计划前询问一次**（与目标确认同一句话问出，不单独刷屏）：
   > "当前目标：增肌。要用高级训练技术吗？不用就按标准组安排～"
2. 用户说要用 / 想看看 → 按上表 A/B 档、结合当天部位与目标水平，**推荐 2-3 个适配框架供挑选**（各附一句话说明）
3. **用户看过推荐后不满意、或犹豫不定 → 回退标准组**，不追问、不劝说；回退后按标准组正常出计划
4. 用户直接点名框架（"今天用金字塔"）→ 跳过推荐，直接确认该框架（仍须过适用表：C 档禁用项要告知原因并建议替代）
5. 计划「技术框架」行标注：【高级训练技术：金字塔组】
6. 参数按框架规则执行，覆盖 volume-params.md 默认值；覆盖点必须在计划中显式声明（如"金字塔组：逐组变重，组间休 2 分钟"）

## 五、与现有规则的冲突裁决

| 冲突 | 裁决 |
|------|------|
| 预疲劳法 vs 排序铁律（孤立不得在复合前） | 用户显式选用预疲劳 → 允许孤立前置，**计划中必须声明"预疲劳框架，顺序有意为之"**；未选用 → 铁律不变 |
| 少次多组（10-15 组）vs 单动作组数铁律（≤5-6 组） | 选用该框架时此动作豁免组数上限，但当日其他动作让路：总容量仍 ≤20 组 |
| 巨型组/超级组（内部不休息）vs 组间休息表 | 组合内部不休息，组合结束后按较重动作档休息；计划中注明 |
| 递减组/金字塔组（一个动作多个重量）vs 日记单重量行 | 日记重量列写阶梯（如「15→10→7.5（递减）」），容量按各重量分段计算后求和 |
| 高级框架参数 vs volume-params 默认参数 | 框架参数覆盖默认值；参数关自检按框架口径核对 |

## 六、来源说明

技术目录整理自用户训练经验与 OB 健身知识库（高级训练技术清单，2026-08-12）；适用表（A/B/C 档）由 Agent 依据各技术的适用/禁用场景反推，用户可逐条修正。强迫次数、诱导重复需搭档，不写入单人动作文档；加压训练法因无护具不纳入。
