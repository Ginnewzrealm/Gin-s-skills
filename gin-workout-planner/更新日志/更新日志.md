## v1.25.0（2026-08-22）

**训练计划支持写回训记 App**

- ✨ **训练计划写回训记**：生成计划并经用户确认后，询问是否写入训记；用户同意则调用 `xunji-training` 技能以 `action: write_plan` 写入，标题 ≤ 4 个汉字
- ✨ **新增 `references/trains-train-writeback.md`**：桥接约定，含参数构造、去重规则、覆盖/新建/取消策略、单写保证、异常处理

- ✨ **写前加锁 + 禁止自动重试**：调用训记前创建临时锁文件，调用后无论成败均解锁；一次失败必须等用户明确"再试"才能再次调用
- ✨ **client_request_id 幂等**：同一份计划使用相同的 `client_request_id`（基于 datestr + body_part + plan_hash），训记服务端如支持幂等可进一步去重

- 🔧 **初始化依赖检测对齐实际目录名**：`kb-structure.md` 中「训记训练技能」「训记饮食技能」改为运行时检测，提示话术同步更新
- 🔧 **计划输出后流程扩展**：`plan-output.md`「输出后」新增用户确认、询问写入训记、本地存档、写回训记四步
- 🔧 **训记训练技能 Key 管理改造**：`xunji-training` 移除硬编码 Bearer token，新增 `scripts/init.py` / `scripts/common.py` / `scripts/get_key.py`；Key 初始化一次后保存到 `~/.config/xunji-training/config.yaml` 并支持 Agent tools 备份，后续复用
- 🔧 **训记写入后验证铁律**：`SKILL.md` 新增规则 12；`trains-train-writeback.md` 明确要求解析 `success === true` 才算成功，看到 `res` 数据不是失败；未确认结果前禁止自动重试；失败话术明确告知「我不会自动重试，只有用户说"重新试"或"再试一次"时才再次调用」
- 🔧 **新增写回记录修复脚本**：`scripts/repair_writeback_log.py` 用于把旧版空数组 `[]` 或异常结构修复为 `{schema_version, records}` 规范结构
- 🔧 **路由表与真源归属更新**：`SKILL.md` 制定训练计划行增加 `trains-train-writeback.md` 引用，规则真源归属段同步补充
