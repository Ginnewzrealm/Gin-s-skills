# 中文简历写作方法论

> N9 管线第⑦步（改写）与第⑨步（初稿确认）必读。

## 总体原则

1. 简历是「证据清单」不是「职责描述」：每条都要回答「你做成了什么」
2. 一页优先：3 年以内经验 1 页，10 年以上最多 2 页
3. 倒序排列：最近的经历在最前
4. 与 JD 对齐：把 JD 最看重的能力放在最显眼位置（事实挑选已完成，改写负责表达）

## 板块字段标准

各板块固定字段结构（工作经历四字段、项目经历三字段、岗位胜任、技能）、写作公式、完整示例与合格线，见 [resume-section-standard.md](resume-section-standard.md)。组装 resume.json 前必读；组装后用 `scripts/resume_structure_check.py` 校验。

## 结构规范

```
姓名 + 联系方式（电话/邮箱/城市/求职意向）
岗位胜任（置顶，2-3 条，与 JD 呼应；知识库存储层仍叫「个人优势」，展示层统一为「岗位胜任」）
工作经历（倒序，每段 3-5 条 bullet）
项目经历（选与 JD 相关的 1-2 个）
教育背景
技能（熟练度分层：熟练/掌握/了解）
```

命名说明：优势是相对的，只有与目标岗位匹配才有意义，因此简历展示层用「岗位胜任」，不用「个人优势」。html_renderer.py 会把岗位胜任/核心亮点/个人优势板块自动置顶，无论 resume.json 中的章节顺序如何。

模板主题切换：输出的 HTML 右上角有「极简 / 投行 / 欧美」三套主题切换键，风格只改变视觉，不改变内容与 ATS 友好性；选择会记忆在浏览器中，导出 PDF 即为当前所选风格。

## 语言风格

- 每条 bullet 以强动词开头：主导/搭建/优化/落地/推动（避免「参与」「协助」开头）
- 一条 bullet 一句话，不超过 50 字
- 数字用阿拉伯数字：「提升 35%」不写「提升百分之三十五」
- 时态统一用完成态，不写「正在负责」（除非在职且进行中）
- 不使用人称代词「我」

## 禁用词清单

| 类别 | 禁用 | 替代 |
|------|------|------|
| 抽象战略词 | 赋能、抓手、闭环、颗粒度、打法（除非 JD 原词） | 具体动作 + 结果 |
| 老板视角词 | 制定公司战略、统筹全局、高瞻远瞩 | 写自己亲手做的事 |
| 模糊词 | 大大提升、效果显著、表现优异 | 数字 |
| 套话 | 吃苦耐劳、学习能力强、有责任心 | 用事实让 HR 自己得出 |

## JD 风格对齐

- 技术岗：突出技术栈匹配 + 性能/规模指标（QPS、延迟、可用性）
- 销售岗：突出业绩数字 + 排名 + 客户层级
- 运营岗：突出增长指标 + 活动/内容规模
- 产品岗：突出需求 impact + 数据验证 + 跨团队推进
- 管理岗：突出团队规模 + 业务体量 + 从 0 到 1 / 扭亏为盈等标志性事件
- 转行模式：弱化旧行业术语（如「楼盘」「案场」），强化可迁移能力（项目管理、客户沟通、数据分析），用新行业语言表达同一事实——**改写措辞，不得改写事实**
