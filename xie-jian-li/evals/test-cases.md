# xie-jian-li 验证测试场景（TC 定义）

> evals.json 中 `covers` 字段的唯一权威定义来源。
> 每个场景：触发语 → 预期路径 → 可验证点。覆盖主路径、异常路径与边界情况。

| TC | 场景 / 触发语 | 预期路径与可验证点 |
|----|--------------|-------------------|
| TC-01 | 首次使用：「我第一次用，帮我整理一下我的工作经历」 | N3(NO)→N4 引导→N5 grilling 一问一答。✅ 目录按 knowledge-structure.md 创建；✅ config.yaml 写入 kb_path；✅ 每次只问一个问题；✅ 说「先到这」可保存退出。异常：拒绝初始化→友好结束 |
| TC-02 | 核心管线：「帮我写简历。JD 如下：……」 | N3(YES)→N9 十步→落盘。✅ HTML 可打开、可编辑、离线无 CDN；✅ 每条可溯源，数字与 KB 一致；✅ 溯源拦截→补事实→重写→再校，不得跳过 |
| TC-03 | JD 截图输入 | 识别图片→提取文字→用户确认→进管线。✅ OCR 失败时引导粘贴文字 |
| TC-04 | JD 分析：「这个岗位值得投吗」 | N8 报告（分数/拆解/红标）落盘 target_roles/。✅ 报告末尾询问是否衔接简历管线；拒绝则正常结束 |
| TC-05 | 求职信：「帮我写一封求职信」 | N10。✅ 先问模板（标准/推荐人/转行/应届）；✅ 300-500 字；✅ 不重复简历条目；超 500 字自动压缩 |
| TC-06 | 意图不匹配：「帮我做 PPT」（连续 3 次） | N19 告知能力范围+功能清单。✅ 连续第 3 次停止回环，建议查看说明或改用其他工具 |
| TC-07 | 增量更新冲突：「我换工作了，新公司是美团……」（同公司同期已有记录） | N3(YES)→N6。✅ 冲突检出并新旧并排；✅ 用户裁决后才写入；✅ 追加不覆盖；✅ changelog 有记录、meta+1 |
| TC-08 | 转行：「我之前做房地产销售，想转 SaaS 客户成功」 | N9 转行分支。✅ 提示转行模式并确认；✅ 可迁移能力优先；✅ 弱化旧行业术语 |
| TC-09 | STAR 故事库：「帮我从经历里提取 STAR 面试故事」 | N11。✅ 五类齐全、每故事三版本；✅ 落盘 面试素材/ 而非 生成物/；✅ 事实与 KB 一致 |
| TC-10 | 面试清单（STAR 缺失）：「帮我准备面试问题」附 JD | N12→（缺 STAR）→N11→N12。✅ 自动先生成故事库（exit 3 契约）；✅ question-bank.md 首次生成于 面试素材/；✅ 15-20 题含简历关联与 STAR 素材 |
| TC-11 | 高管简历：「帮我写一份高管简历，投 VP 岗位」 | N13。✅ 4-6 个战略级成就；✅ 六段结构完整；✅ 成就可溯源 |
| TC-12 | 冷邮件：「帮我写一封冷邮件给字节 HR」 | N14。✅ 200-300 字、1-2 个亮点、明确下一步；✅ 不联网调研；✅ 无目标信息时询问补充，补不了不生成 |
| TC-13 | 网申答案：「帮我填网申：1.为什么加入我们？2.……」 | N15。✅ 正确识别问题类型；✅ 每题 1-3 句；✅ 不与简历简单重复 |
| TC-14 | ATS 诊断：「帮我做个 ATS 检查，简历用上周那份」 | N16。✅ JD 关键词逐项覆盖；✅ 格式建议；✅ 支持指定简历文件或从 KB 临时生成 |
| TC-15 | 执行失败路径：渲染脚本失败（如模板缺失） | N9(失败)→N17。✅ 告知具体环节与原因；✅ 给重试/跳过/手动建议；✅ 不假装成功、不伪造产物路径 |
| TC-16 | KB 路径异常：kb_path 有值但目录结构不完整 | N3(NO 路径异常)→N4 三选项。✅ 提示路径可能变更；✅ 重新初始化/修改 kb_path/暂不处理三选项 |
| TC-17 | BOSS 打招呼语：「我在 BOSS 上想跟招聘方打个招呼」 | 求职信 boss 模板。✅ 免问模板直接 `--template boss`；✅ 60-120 字、上限 150（`--check --template boss`）；✅ 开场 ≤35 字含岗位+最强卖点；✅ 仅 1 个量化亮点；✅ 无表忠心段、无「期待面试」客套 |
| TC-18 | 技能清单门禁：「我会商务谈判和团队搭建，帮我记到知识库」 | skills-inventory-standard。✅ 清单分「通用能力/专属能力」两段；✅ 专属条目「技能名（熟练度）｜佐证」、通用条目「能力名（证据：强/中）｜场景：…」（2 个场景起）；✅ 整批展示、用户确认后才 append-skill（通用加 --type general）写入；✅ 未确认不落盘；✅ AI 推断同门禁；✅ 无佐证/无场景的条目拒收 |
| TC-19 | 技能深挖：「把『商务谈判』写详细点，面试要用」 | skill-mining-playbook。✅ 支架式提问（选项/填空/示例锚定/草稿纠偏），不抛开放式大问题；✅ 一问一答、漏斗顺序；✅ 核心技能挖全五维，其余从简；✅ 五维块用户确认后写入 skill_details.md 并 facts_parser 重建；✅ 反事实测试不过则回行动层重挖 |
| TC-20 | 简历模板渲染规格（TC-02 产物延伸） | N9-⑩。✅ 五个板块标题为中文+右侧英文小字（岗位胜任 CORE COMPETENCIES 等）；✅ 岗位胜任自动置顶；✅ 圆点 bullet + 字段徽章；✅ 工具栏含三主题切换/编辑/保存/还原/导出 PDF；✅ 结构校验未过禁止渲染 |

## 覆盖汇总

- 节点/子功能：N1-N19 主路径 + 异常边全覆盖（TC-01~16）；v1.1~v1.4 新功能（boss 模板、技能清单、技能深挖、模板渲染规格）由 TC-17~20 覆盖
- 异常路径：TC-01 拒绝初始化、TC-03 OCR 失败、TC-06 三次回环、TC-07 冲突、TC-12 无目标信息、TC-15 执行失败、TC-16 路径异常
- 边界情况：输入多样性（TC-03）、跨技能衔接（TC-04、TC-10）、门禁与确认（TC-18、TC-19）
