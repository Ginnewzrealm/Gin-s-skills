# 使用 Skill 后的行为验证

## 场景

与 `baseline.md` 使用同一请求：非技术用户只描述客服查看订单、正常接单、问题订单通过微信询问客户。

## 实际响应

> 没问题，你只要按平时做事的方式讲，不需要懂软件或流程图。
>
> 我先确认一下目前的流程：收到订单 → 客服查看 → 没问题就接单；有问题就在微信里询问客户。
>
> 这里有没有说错或漏掉什么？

## 对照结果

| 期望 | 结果 |
|---|---|
| 使用非技术语言 | 通过 |
| 一次只问一个问题 | 通过 |
| 不补写未知步骤 | 通过 |
| 先复述已知事实再继续 | 通过 |
| 未确认前不生成终稿 | 通过 |

基线中的“客户回复后再次检查”等推测没有再被写成事实，四个并发问题也被收敛为一个确认问题。
