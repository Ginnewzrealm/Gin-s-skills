# 工具映射

> pdca-report 读取数据、pdca-write 写入数据时读取本文件。

## Sheets 操作

| 操作 | 工具/模式 | 说明 |
|---|---|---|
| 验证表格和子表 | `lark-cli sheets +workbook-info` | 初始化时确认目标表格和子表存在 |
| 读取子表表头 | `lark-sheets` skill：`read_header` | 建立字段名→列字母映射 |
| 读取日期列 | `lark-sheets` skill：`read_date_column` | 获取所有已有日期及其行号 |
| 读取指定日期行 | `lark-sheets` skill：`read_daily_rows` | 读取某日完整数据 |
| 查找周号行 | `lark-sheets` skill：`find_week_row` | 在 PDCA 输出表中定位周号 |
| 创建周号行 | `lark-sheets` skill：`create_week_row` | 周号不存在时按升序插入 |
| 写入字段 | `lark-sheets` skill：`write_fields_by_name` | 按字段名→列字母映射批量写入 |
| 回读校验 | `lark-sheets` skill：`verify_row_values` | 写入后整行回读比对 |

完整命令模板见 `references/sheets-calling-patterns.md`。

## 日期定位规则

- 「每日记录」的日期列为 A 列，格式统一为 `YYYY-MM-DD`
- 读取日期列建立 `日期 → 行号` 映射
- 本周 7 天中缺失的日期计入数据质量债

## CellValue 写入格式

| 字段类型 | Sheets 写入格式 |
|---|---|
| 文本 | `"普通文本"` |
| 数字 | `72.4` |
| 日期 | `"2026-08-26"`（YYYY-MM-DD） |
| 单选 | `"选项名"` |
| 多选 | `["选项1", "选项2"]` |
| 复选框 | `true / false` |

## Python 解析注意事项

- `lark-cli sheets +csv-get` 返回 `annotated_csv`，每行前缀 `[row=N]` 为实际行号
- `col_indices[i]` 为第 i 列的列字母，禁止手数
- 读取前通过 `current_region` 确认实际数据范围，避免漏读
