# 报告生成规则（pdca-summary 模块）

> M1-M9 扫描完成后读取本文件，生成 9 字段报告。

## 输入

- M1-M9 JSON（来自诊断模块）
- 上期输出表记录（可能为空）
- 知识库方法论文档（本技能 `knowledge/` 目录，只读）——三轴判断、下周行动的「制定→反馈→修正→执行」依据
- 数据质量说明（来自双闸校验，含缺轴信息）

## 9 字段结构（A6 + 一~七 + A5）

| 字段 | 内容 |
|------|------|
| 本期闭环总结（A6） | 新发现/传承/已解决/下期优先 |
| 一、现状与目标 | 体重/腰围/体脂率与目标差距 |
| 二、减脂阶段性分析 | 三轴判断 |
| 三、做得好的 | M正常项 + 标准化建议 |
| 四、存在的问题 | M有问题项 + 假设验证路径 |
| 五、上周行动效果 | 上期行动追踪 |
| 六、下周行动 | Why/What/When/How |
| 七、数据质量 | 覆盖率 + 异常说明 |
| 八、遗留传递（A5） | 未闭环问题历史传承 |

## 关键规则

1. **三轴判断缺轴降级**：腰围或体脂率本期未测量时，「一、现状与目标」对应项标注「本期未测量」，「二、减脂阶段性分析」降级为两轴判断，并在「七、数据质量」中说明。不得编造缺失数据，不得因此中断报告。
2. **下周行动的方法论依据**：必须查阅知识库 `knowledge/减脂速度评估与调整频率指南.md`（重点第四~七节：评估节奏、触发调整条件、调整幅度与顺序、减脂期边界），所有数字以知识库原文为准，不得凭印象改写，不得在报告中引用与知识库不一致的旧口径。
3. **首次运行**：上期输出表为空时，A6/A5 输出简化版（说明「首期，无传承数据」），不报错。
4. **遗留传递（A5）**：未闭环问题须携带完整历史——首次发现周号、已传承期数、验证状态；已排除的问题标注排除原因。
5. **边界**：仅输出减脂数据分析与决策建议；疑似疾病信号只提示咨询医生，不下诊断结论。

## 输出

9 字段报告文本，用于写入周表（见 `输出表结构.md`），同时供完成通知渲染（见 `话术模板.md`）。
