# 飞书通知规则（pdca-notify 模块）

> 需要发送任何通知时读取本文件与 `话术模板.md`。

## 三类通知

| 通知 | 触发时机 | 模板 |
|------|---------|------|
| 开始通知 | 主流程调度开始 | 简短：已启动 + 正在读取数据 |
| 完成通知 | 周表写入回执确认成功 | 完整模板：代谢状态灯 + 闭环总结 + 做得好/需关注/有问题 + 上周行动 + 下周行动 + 数据质量 + 遗留传递 |
| 错误通知 | 异常/终止条件命中 | 错误类型 + 描述 + 影响范围 + 检查清单 |

模板原文见 `话术模板.md`，渲染时严格按模板结构填充，不得自行增删板块。

## 关键规则

- 完成通知的代谢状态灯：🟢 正常 / 🟡 关注 / 🔴 严重，依据 M1-M9 有问题的数量与严重度
- 遗留传递区：🔴 传承中（首次发现周号 + 传承期数）、🟡 初步锁定、❌ 已排除
- cron 无人值守场景下，通知是唯一触达渠道，三类通知都必须发送，不得静默
