# 训记训练技能 桥接约定

> 触发条件：训练日记场景获取训练数据、动作问答需查训记动作目录、或初始化做依赖检测时，必须先读本文件。
> 前置条件：用户环境中已安装「训记训练技能」。

## 一、职责边界

调用方技能（本技能）负责：
- 检测「训记训练技能」是否已安装
- 构造调用参数并发起调用
- 接收返回结果并按本技能规则使用（写入训练日记、回流索引与动作文档）

被调用方技能（训记训练技能）负责：
- 训练数据的查询、鉴权、限频
- 返回数据的格式整理
- 错误原因的定义与返回

本技能明确不执行以下操作：
- 不直接调用任何训练接口
- 不存储或读取任何训练相关凭证；技能文件与 `_skill-config.json` 中都不出现训练 Key
- 不替代「训记训练技能」完成训练数据的记录与修改
- 与「训记饮食技能」互为独立（约定见 `trains-diet-bridge.md`），两者都只检测安装 + 调用 + 接收结果，互不混用；两个技能的凭证各自归各自管理，本技能一律不经手

## 二、依赖检测

检测方式：初始化或进入训练日记场景时，检测「训记训练技能」是否存在于当前用户环境。

- 已安装 → 一句话告知训练数据桥接已就位，继续调用流程
- 未安装 → 提醒用户安装「训记训练技能」并说明安装途径；同时启用备用通道：训练日记走「用户口述/粘贴」，主流程不中断。禁止尝试调用其任何功能，禁止模拟或伪造返回结果

## 三、输入参数

| 参数名 | 类型 | 必填 | 取值范围/格式 | 说明 |
|--------|------|------|---------------|------|
| date | string | 是 | YYYY-MM-DD | 要查询的训练日期 |

## 四、输出结果

| 字段名 | 类型 | 存在条件 | 说明 |
|--------|------|----------|------|
| status | string | 始终存在 | "success" 表示成功，"error" 表示失败 |
| records | array | status = "success" 且当日有记录 | 训练记录列表，每条含动作名称、组数、次数、重量；按返回口径原样使用 |
| error_msg | string | status = "error" | 用户可理解的错误原因描述，原样展示 |

## 五、异常处理

| 异常情况 | 处理方式 |
|----------|----------|
| 训记训练技能未安装 | 提醒用户安装，训练日记走「用户口述/粘贴」备用通道，主流程不中断 |
| 调用失败/返回 status = "error" | 原样展示 error_msg，降级为用户口述/粘贴通道；禁止自动重试，禁止修改或篡改错误信息 |
| 当日无训练记录 | 如实告知用户，属正常情况，不算失败 |
| 返回结果字段缺失/解析失败 | 缺失项标注「待补充」，请用户核对；禁止估算，禁止从其他来源编造数据补全 |
| 用户要求记录/修改训练数据 | 引导用户使用「训记训练技能」，本技能禁止代劳 |
