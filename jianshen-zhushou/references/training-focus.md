# 训练侧重点（真源）

> 何时读我：初始化录入侧重点、出训练计划做侧重点确认与参数解析、用户口头更新侧重点时，必须先读本文件。
> 本文件是「训练侧重点」的唯一真源：文件格式、三档标签、解析链、联动规则。数据本体存知识库根目录 `训练侧重点.md`，其他文件只引用不复制。

## 1. 数据文件与格式（模板 v2）

位置：`{知识库根}/训练侧重点.md`，初始化时创建（无偏好也建空骨架）。

固定格式（分区标题与用词不可改动）：

```markdown
# 训练侧重点

> 格式说明：二~四章每条一行「- 对象：内容（备注/起始日期）」；次数档只写三档之一：4-8 练力气 / 8-12 练维度 / 12-20 肌肉觉知、控制、耐力与塑形（双档写法：对象：复合 X-X / 孤立 X-X）；等长动作可写「时间维持」；部位策略用词只用 加强 / 维持 / 避开；动作用词只用 多做 / 少做 / 避开

## 一、整体原则
- （暂无）

## 二、部位策略
- （暂无）

## 三、次数偏好
- （暂无）

## 四、动作侧重点
- （暂无）
```

- **一、整体原则**（自由叙述区）：用户的训练哲学、审美目标、体感标准（如"下半身为主力""上半身不变厚变宽"），按 bullet 整理写入。Agent 只做背景理解，**不逐条解析**；与二~四章条目冲突时必须指出并请用户裁决，禁止静默选一个
- **二、部位策略**：对象 = 一级分类 或 细分对象（肌肉名 / rules.md 目标部位标签词表）；策略三词——`加强`（排序走弱项优先前移）、`维持`（最低限度保持：组数压下限、负荷不推进、频率可降；选材**不排除**）、`避开`（伤病等原因，硬排除）；备注原因与起始日期
- **三、次数偏好**：对象分两级——部位级行 = 该部位默认；**细分级行**（肌肉名或目标部位标签）= 例外，**优先于部位默认**（如「臀中肌：12-20」优先于「臀髋部：4-8」；「胸部中缝：8-12」经由动作文档「目标部位」标签匹配）。单档一行一档；**双档**按动作类型分档（如「臀髋部：复合 4-8 / 孤立 12-20」）；等长动作（平板支撑类）写「时间维持」，不走 RM 体系
- **四、动作侧重点**：动作名 + `多做`/`少做`/`避开`；`避开` = 动作级黑名单（硬排除并在计划声明）；`少做` 只降选材优先级，**不等于排除**

## 2. 三档标签（全局统一口径）

| 次数档 | 标签 | 约当负荷（%1RM） |
|--------|------|------------------|
| 4-8 次 | 练力气（力量） | 75-87% |
| 8-12 次 | 练维度（增肌） | 72-80% |
| 12-20 次 | 肌肉觉知、控制、耐力与塑形 | 57-72% |

负荷不单独存：次数档定了，%1RM 由 volume-params.md 公式 `(37-次数)/36` 自动得出；本表仅为对照。

## 3. 录入规则

- 初始化第 4b 步选项式提问录入（话术见 kb-structure.md）；之后可随时口头补录
- 用户口头表达侧重点（"记一下，臀大肌我想练力气"）→ Agent 按本文件格式写入对应分区并**复述确认**；禁止把用户原话不经格式化直接塞入
- **整体原则**：用户给出大段叙述（训练哲学/审美目标）→ Agent 提炼为 bullet 写入「一、整体原则」并复述确认；只做背景理解，不拆成解析条目
- 形态类意向（"中缝我想练维度""上胸重点练"）→ 词表里有对应标签就直接录「三、次数偏好」细分级行（经动作文档目标部位标签匹配）；词表没有 → 报告用户，确认后扩充 rules.md 词表，禁止临场造词
- 文件只记有偏好的行；无偏好的部位/肌肉/动作不占行，解析时走默认

## 4. 计划场景联动（解析链，每个动作走一遍）

1. 读动作文档「一、目标肌肉」的主要目标肌肉 **+ （三）目标部位标签**（旧文档无标签则只按肌肉匹配，静默降级）**+ frontmatter 动作类型** → 查 `训练侧重点.md`
2. 次数偏好行是**双档**时 → 按该动作的动作类型取档（三大项/复合动作取「复合」档，孤立动作取「孤立」档）
3. **有效次数档 = 细分级偏好（肌肉名行、目标部位标签行，二者同级）> 部位级偏好 > 全局 `training_goal` 默认区间**（volume-params.md 第二节）；同一动作的肌肉行与标签行命中不同档位 → 属信息冲突，填「待用户确认」并向用户说明，禁止任选其一
4. **安全天花板**（不可被偏好突破，压住时必须声明）：学习期重量让步（training-stages.md）、新手固定 8-10 次（volume-params.md）、负荷必须有出处
5. 有效次数档**一次解析、四处消费**：① 次数区间 ② 负荷 %1RM（volume-params 公式）③ 组间休息（4-8 → 3-5 分钟；8-12 → 90 秒-2 分钟；12-20 → 30-90 秒）④ 训练技术适配（4-8 视同增力、8-12 视同增肌、12-20 视同肌耐力，见 techniques.md 适配表）；「时间维持」动作不消费 ①②，按等长动作规则给秒数
6. 覆盖默认值的动作必须在计划中**显式声明**（"臀冲走 4-8，按侧重点覆盖默认 8-12"）

## 5. 确认回路（日常纠错，必须生效）

- 每次出计划，合并确认话术（与目标/水平/阶段确认同一段，见 plan-output.md 步 5-5c）**必须念出本次涉及动作的有效次数档与部位策略**："当前目标：增肌｜水平：中级｜阶段：卧推渐进期、飞鸟学习期｜侧重点：臀腿复合 4-8、胸部维持、避开肩臂——要改说一声"
- 用户提出修改 → **先更新对应文件**（`训练侧重点.md` / 动作 frontmatter / `_skill-config.json`）再继续编排
- 该段确认话术缺失 = 检查表 ⓪ 流程关 NO-GO，禁止发送计划

## 6. 选材与排序联动

- **避开 > 一切（含三大项必选）**：部位避开 = 排除该一级分类全部动作；**细分避开** = 排除目标部位标签或主要目标肌肉命中该对象的动作（如"避开下背"→ 挺身/背伸类排除，划船保留）；**动作避开**（四、黑名单）= 排除该动作。三种避开均须在计划「今日提醒」声明；热身匹配同步跳过避开部位
- **维持**：该对象动作组数一律压到下限（volume-params.md 第三节）、负荷不推进（沿用历史重量，不加码）、排序不享受前移；选材不排除、不声明覆盖。**维持只压组数与负荷，不减少角度覆盖**（v1.23.0 起）——该部位应覆盖的细分角度照常各保留至少 1 个动作，按下限组数执行；维持日的样子是"每个角度 1 个动作 × 下限组数"，不是砍掉角度
- **加强 = 弱项优先**：ordering.md 弱项优先条款读「二、部位策略」加强行（一级分类与细分对象都算；细分加强 = 命中动作排序前移）；`_skill-config.json` 的 `priority_muscles` 字段已废弃（旧值迁移见 kb-structure.md）
- **少做 ≠ 排除**：仅降选材优先级；三大项仍必选，除非用户明确说"避开"
- **撞车裁决**：避开 > 维持/加强；同一对象同时标维持与加强 → 待用户确认
