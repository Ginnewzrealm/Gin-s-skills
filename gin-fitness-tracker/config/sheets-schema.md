# Sheets 后端表结构参考

> 适用于 `fitness.backend = feishu_sheets`（默认）。

本文件为参考模板。运行时**不硬编码字段名**，应通过 `lark-sheets` skill 读取表头行动态获取字段列表。

---

## 每日记录子表

默认子表名：`每日记录`

| 行/列角色 | 说明 |
|-----------|------|
| 表头行（默认第 1 行） | 字段名，如：日期、周编号、晨起体重、体脂率、BMI、腰围、臀围、腰臀比、睡前体重、早晚体重差、大解状态、入睡时间、起床时间、睡眠时长、晨起心率、入睡难度、半夜醒来、早起状态、午后能量低谷、傍晚情绪状态、睡前异常清醒、起床饥饿程度、早餐时间、早餐饥饿时间、早餐饥饿程度、早餐饥饿速度、午餐时间、午餐后困倦、午餐饥饿时间、午餐饥饿程度、午餐饥饿速度、晚餐时间、总热量、蛋白、碳水、脂肪、碳水渴望、训练欲望、训练状态、力量、有氧、其他备注 |
| 数据行（从第 2 行开始） | 每日一条记录，按日期升序排列 |
| 日期列（默认 A 列） | 格式 `YYYY-MM-DD`，用于按日期定位行 |
| 周编号列（默认 B 列） | Sheets 公式自动计算，周日为一周第一天 |

### 字段清单

每日记录子表共 42 个字段。完整的字段名、时段、类型、写入方、选项、填写说明统一维护在「字段元数据」子表中，详见 `config/field-metadata-schema.md`。

表头行仅保留字段名，例如：

```
日期、周编号、晨起体重、体脂率、BMI、腰围、臀围、腰臀比、睡前体重、早晚体重差、大解状态、入睡时间、起床时间、睡眠时长、晨起心率、入睡难度、半夜醒来、早起状态、午后能量低谷、傍晚情绪状态、睡前异常清醒、起床饥饿程度、早餐时间、早餐饥饿时间、早餐饥饿程度、早餐饥饿速度、午餐时间、午餐后困倦、午餐饥饿时间、午餐饥饿程度、午餐饥饿速度、晚餐时间、总热量、蛋白、碳水、脂肪、碳水渴望、训练欲望、训练状态、力量、有氧、其他备注
```

### 字段元数据子表

默认子表名：`字段元数据`

| 字段名 | 时段 | 类型 | 写入方 | 选项 | 填写说明 |
|--------|------|------|--------|------|----------|
| 晨起体重 | 晨间 | 数字 | Agent | — | 晨起空腹体重，单位 kg，保留 2 位小数 |
| 睡眠质量 | 晨间 | 单选 | Agent | 良好/一般/差 | 睡眠质量评估 |
| 总热量 | 晚间 | 数字 | Agent | — | 当日总热量摄入，单位 kcal |

完整清单见 `config/field-metadata-schema.md`。

**运行时规则**：
1. Agent 先读取「每日记录」表头行获取字段名。
2. 再读取「字段元数据」子表，获取每个字段的时段、类型、写入方、选项、填写说明。
3. 所有字段的填写格式、单位、选项以子表为准，不得自行推断。
4. 若子表中不存在某字段，回退到字段名模式匹配。

### 公式列说明

| 字段名 | 公式职责 | 周起点约定 |
|--------|---------|-----------|
| 周编号 | 根据 A 列日期计算所在周数 | 周日为一周第一天，每年第一个周日为 Week 1 第 1 天 |
| 睡眠时长 | 根据同行的入睡时间、起床时间计算 | — |
| 腰臀比 | 根据同行的腰围 / 臀围计算 | — |
| 早晚体重差 | 根据前一行睡前体重 - 当日晨起体重计算 | 跨行引用，首日无前序行时可为空 |

**BMI 特殊约定**：BMI 不由 Sheets 公式计算，而由 Agent 根据用户身高和当日晨起体重计算后写入静态数值。用户身高从「用户配置」子表读取。

### 自动创建日期行

每日记录表采用**自动按日期升序创建空行**模式：

1. 写入或轮询某日期前，先调用 `lark-sheets` skill 在日期列查找该行。
2. **行已存在** → 直接写入字段值。
3. **行不存在** → 自动插入新行，使所有日期行始终保持升序排列。

**插入规则**：
- 找到日期列中最后一个 `< 目标日期` 的行。
- 在其下一行插入空白行，并填入目标日期。
- 新行的公式列（周编号、睡眠时长、腰臀比、早晚体重差）由 Sheets 自动填充（通过拖拽或数组公式）。
- 若表格使用了数组公式覆盖整列，则新行会自动继承公式。
- 若表格为空（无数据行），则在第 2 行写入目标日期。

**示例**：

| 日期 | 周编号 | 晨起体重 | ... |
|------|--------|----------|-----|
| 2026-08-19 | Week 34 | 68.5 | ... |
| 2026-08-20 | Week 34 | 68.2 | ... |
| 2026-08-21 | Week 34 | — | ... |

若用户补录 2026-08-18，则在 2026-08-19 之前插入一行，日期填入 `2026-08-18`。

### 约定

1. **日期行自动创建**：技能负责自动按升序插入日期行，无需用户手动添加。
2. **字段名唯一**：表头行中字段名不可重复。
3. **日期列不可为空**：且格式统一为 `YYYY-MM-DD`。
4. **单选/多选字段**：通过飞书表格「数据验证 → 下拉选项」维护，写入前必须通过 `lark-sheets` skill 读取下拉选项并校验。

## 用户配置子表

默认子表名：`用户配置`

| 配置选项 | 值 | 更新时间 |
|---------|-----|---------|
| 目标阶段 | 减脂期 | 2026-08-01 |
| TDEE | 2200 | 2026-08-01 |
| 当前体重 | 68.5 | 2026-08-20 |
| 身高 | 175 | 2026-08-20 |

### 约定

1. 每行一个配置项，`配置选项` 列唯一。
2. `值` 列统一为文本或数字，由业务逻辑解析。
3. 初始化时若子表不存在，返回 `TABLE_NOT_FOUND` 错误，提示用户手动创建。健身追踪 skill 不自动创建子表。
4. **新增必填项「身高」**：用于 Agent 计算 BMI。

## 选项子表（可选）

默认子表名：`选项`

若需严格限制单选/多选字段取值，可维护一张选项表：

| 字段名 | 可选项 |
|--------|--------|
| 大解状态 | 🟢正常1次 / ⚠️异常无/少 / 🔴连续异常 / 🟢正常 / 少量 |
| 训练状态 | 🟢有力 / 正常 / 🔴无力 / 无 |

写入单选/多选字段前，通过 `lark-sheets` skill 读取对应字段的可选项（数据验证下拉选项或「选项」子表），校验用户输入映射后再写入。

## 与 DataStore 的映射

| DataStore 方法 | Sheets 实现 |
|----------------|-------------|
| `getUserConfig()` | 读取「用户配置」子表，返回 `{ 配置选项: 值 }` |
| `updateUserConfig(changes)` | 在「用户配置」子表中找到对应配置项行，更新「值」列 |
| `writeDailyRecord(date, fields)` | 在「每日记录」子表的日期列中查找 `date` 所在行；不存在则按升序自动插入；存在则更新对应字段列的单元格 |
| `getDailyRecord(date)` | 在「每日记录」子表中找到 `date` 所在行，读取整行 |

所有具体读写操作均委托给 `lark-sheets` skill，健身追踪技能不直接调用 `lark-cli sheets` 命令。
