# 用户配置表结构定义

## 设计原则

用户配置表采用**行存储**，每行是一个配置项。新增配置项只需加一行，不用改表结构。

**值统一存储为文本**，在写入时由技能自动转换类型。

## 字段定义

| 配置选项 | 类型 | 示例 | 说明 |
|---------|------|------|------|
| 目标阶段 | 单选 | 减脂期/维持期/增肌期 | 当前营养目标所属阶段 |
| TDEE | 文本 | 1936 | 每日总能量消耗（存储为文本，AI 读取时解析为数字）|
| 目标热量 | 文本 | 1936 | 每日目标摄入热量 |
| 蛋白目标 | 文本 | 124 | 每日蛋白质目标（g） |
| 脂肪目标 | 文本 | 69 | 每日脂肪目标（g） |
| 碳水目标 | 文本 | 205 | 每日碳水目标（g） |
| 当前体重 | 文本 | 68.25 | 最近记录的体重 |
| 当前体脂 | 文本 | 23.8 | 最近记录的体脂率 |
| 身高 | 文本 | 175 | 用户身高（cm），用于计算 BMI |
| 调整信号 | 文本（JSON） | {...} | 健身复盘写入的调整信号 |
| 当前阶段 | 单选 | 减脂期 | 与"目标阶段"保持一致 |
| 减脂期开始 | 文本 | 2026-07-01 | Phase时间轴 |
| 减脂期结束 | 文本 | 2026-09-30 | Phase时间轴 |
| 维持期开始 | 文本 | 2026-10-01 | Phase时间轴 |
| 维持期结束 | 文本 | 2026-12-31 | Phase时间轴 |
| 增肌期开始 | 文本 | — | Phase时间轴 |
| 增肌期结束 | 文本 | — | Phase时间轴 |
| 碳水循环启用 | 文本 | false | 默认关闭 |
| 碳水训练日目标 | 文本 | 242 | 训练日碳水目标（g） |
| 碳水休息日目标 | 文本 | 124 | 休息日碳水目标（g） |
| 每周训练频率 | 文本 | 4 | 次/周 |
| 固定训练日 | 文本 | 周一,周三,周五,周六 | 碳水循环训练日列表 |

## 调整信号 JSON Schema

`调整信号` 字段由健身复盘层写入，健身规划层读取。格式如下：

```json
{
  "week_number": "2026-W29",
  "adjustment_signals": [
    {
      "metric": "碳水",
      "status": "超标",
      "current": 196,
      "target": 160,
      "unit": "g",
      "action": "减少",
      "amount": "-36g",
      "reason": "碳水占42.7%，超目标范围35-40%",
      "confidence": "high",
      "expected_outcome": "缺口从-97kcal扩大到约-200kcal"
    }
  ],
  "needs_planning_review": true,
  "summary": "碳水超标是主要问题，建议下周碳水目标定在160g"
}
```

### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| `metric` | 字符串 | 调整指标：碳水/脂肪/蛋白质/阶段进度/... |
| `status` | 字符串 | 超标/不足/正常/效果不明显 |
| `current` | 数字/字符串 | 当前值 |
| `target` | 数字/字符串 | 目标值 |
| `unit` | 字符串 | 单位 |
| `action` | 字符串 | 减少/增加/维持/建议延长/建议切换 |
| `amount` | 字符串 | 调整幅度，如"-36g" |
| `reason` | 字符串 | 调整原因 |
| `confidence` | 字符串 | high/medium/low |
| `expected_outcome` | 字符串 | 预期效果 |
| `needs_planning_review` | 布尔 | 是否需要触发健身规划 |
| `summary` | 字符串 | 供用户阅读的信号摘要 |

### 调整优先级

**优先级**：碳水 → 脂肪 → 蛋白质

| 优先级 | 调整目标 | 原因 |
|-------|---------|------|
| 1️⃣ | 先动碳水 | 对总热量影响最直接，调整最灵活 |
| 2️⃣ | 再动脂肪 | 调整要谨慎，影响激素 |
| 3️⃣ | 最后动蛋白质 | 肌肉保留核心，一般不动 |

## 读写权限

| 配置项 | 健身追踪 | 健身复盘 | 健身规划 |
|---------|---------|---------|---------|
| 当前体重 | 写 | 读 | 读 |
| 当前体脂 | 写 | 读 | 读 |
| 目标热量/蛋白/脂肪/碳水 | 读 | 读 | 写 |
| 调整信号 | 读 | 写 | 读 |
| 当前阶段/起止日期 | 读 | 读/建议 | 写 |
| 碳水循环相关 | 读 | 读 | 写 |
