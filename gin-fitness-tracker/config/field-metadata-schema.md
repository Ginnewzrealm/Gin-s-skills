# 字段元数据子表

> 适用于 `fitness.backend = feishu_sheets`。

本文件定义「字段元数据」子表的结构与内容。该子表用于统一约束 AI Agent 的填写行为：字段含义、时段、类型、选项、填写格式、单位、写入方等。

**运行时，Agent 必须优先读取此子表**。若字段在子表中存在，严格按子表定义执行；若不存在，再回退到字段名模式匹配。

---

## 子表结构

默认子表名：`字段元数据`

| 列名 | 必填 | 说明 |
|------|------|------|
| 字段名 | ✅ | 与「每日记录」子表表头行完全一致 |
| 时段 | ✅ | 晨间 / 午间 / 晚间 / 全天 / 元字段 |
| 类型 | ✅ | 数字 / 文本 / 单选 / 多选 / 日期 / 公式 |
| 写入方 | ✅ | Agent / Sheets |
| 选项 | — | 单选/多选字段的可选值，用 `/` 分隔 |
| 填写说明 | ✅ | 字段含义、单位、格式、特殊规则 |

## 使用规则

1. **运行时优先读取**：`collect-data` / `query-data` / `write-verify` 在读取表头行之后，必须读取「字段元数据」子表。
2. **严格按子表执行**：字段的时段、类型、写入方、选项、填写说明以子表为准，不得自行推断。
3. **字段缺失时回退**：若子表中不存在某个字段，先回退到字段名模式匹配；仍无法判断时，视为全天/元字段，继续轮询不停止。
4. **选项必须原样复制**：单选/多选字段的写入值必须从子表「选项」列中完整复制（含 emoji、空格、大小写）。
5. **公式字段禁止写入**：「写入方」为 Sheets 的字段，Agent 只读取其计算结果，不得写入任何值。
6. **BMI 特殊处理**：「写入方」为 Agent，但值不是用户直接输入，而是由 Agent 根据晨起体重和身高计算后写入。
