# gin-problem-finder 方法论 v0.3 修订方案

## 背景

v2 在「纯净水」「减脂」两个主题试运行后，发现以下方法论盲区：

1. **评估/衡量维度缺失**——任何主题都缺「目标/标准/成败判定」
2. **亚群体差异覆盖浅**——只扫「男性/女性/老人/青少年」3 大类，遗漏「慢性病/运动员/孕产期/特殊生理期」
3. **心理/行为维度完全缺失**——v2 完全没扫「动机/情绪/习惯/暴食应对」
4. **跨场景组合查询缺失**——v2 没主动组合「主题 + 其他场景」

## 4 条修订（v3）

### 修订 M1：覆盖度矩阵增加 4 个元维度

Q10 覆盖度矩阵原 8 子领域 → **升级为 8 + 4 = 12 必扫子领域**：

| # | 子领域 | 是否新增 |
|---|--------|----------|
| 1-8 | 原 8 子领域（基础认知/实操方法/适用人群/常见障碍/效果评估/风险与边界/进阶路径/心理建设） | 原 |
| **9** | **目标与评估**（必查） | **v3 新增** |
| **10** | **特殊亚群体**（必查） | **v3 新增** |
| **11** | **心理/行为**（必查） | **v3 新增** |
| **12** | **跨场景组合**（必查） | **v3 新增** |

### 修订 M2：检索词固定 4 类模式

每个主题必跑这 4 类检索词（不管主题是什么）：

```yaml
模式 1 - 评估维度:
  - "{主题} 目标 标准"
  - "{主题} 怎么判断 有效"
  - "{主题} 多久见效"

模式 2 - 亚群体:
  - "{主题} 女性 注意"
  - "{主题} 男性 区别"
  - "{主题} 老年人 风险"
  - "{主题} 青少年 影响"
  - "{主题} 孕妇 哺乳期"
  - "{主题} 慢性病 糖尿病 高血压 禁忌"
  - "{主题} 运动员 健身"

模式 3 - 心理行为:
  - "{主题} 心理 情绪"
  - "{主题} 暴食 应对"
  - "{主题} 习惯 坚持"
  - "{主题} 动机 放弃"

模式 4 - 跨场景:
  - "{主题} 感冒 生病"
  - "{主题} 出差 旅行"
  - "{主题} 加班 熬夜"
  - "{主题} 经期 生理期"
  - "{主题} 怀孕 哺乳"
```

### 修订 M3：评估标准问题必检清单（不管什么主题）

每个主题必查 4 类评估标准问题：

```
1. 成功标准是什么？
   例（减脂）：每周减重 0.5-1kg 是合理速度
   例（纯净水）：电导率 ≤10μS/cm 是国家标准

2. 失败标志是什么？
   例（减脂）：闭经、头晕、基础代谢大幅下降
   例（纯净水）：电导率 >10 即不合格

3. 量化指标有哪些？
   例（减脂）：BMI、腰围、体脂率
   例（纯净水）：pH、TDS、菌落总数

4. 时间维度？
   例（减脂）：每周减重、每月减重、合理周期 3-6 个月
   例（纯净水）：保质期、开封后 7-10 天
```

### 修订 M4：亚群体扫描模板

```
主题 = {用户输入}
亚群体池 = [
  "女性", "男性", "青少年", "老人", "孕妇", "哺乳期",
  "糖尿病", "高血压", "甲状腺", "高血脂",  # 慢性病
  "运动员", "健身爱好者", "体力劳动者"     # 特殊身份
]

为每个亚群体生成查询:
- "{亚群体} {主题} 区别"
- "{亚群体} {主题} 注意"
- "{亚群体} {主题} 禁忌"
```

## v3 试运行：用「减脂」重新验证

新增 4 类元维度 + 12 个必跑检索词 + 评估必检清单 + 亚群体模板，重新跑「减脂」主题。

预期新增问题数量：20-30 条（覆盖评估/亚群体/心理/跨场景 4 维度）。

## v3 验证通过后 → 直接写 SKILL.md

SKILL.md 章节：

```
1. 触发描述（description）
2. 输入/输出契约
3. 8 步流程（含 v3 的 4 元维度强制扫描）
4. QM1-QM3 三判定规则
5. 频次门槛 + 饱和停止
6. 路径策略（用户指定 + 首次配置）
7. 输出格式（JSON + Markdown）
8. 审计报告（必含 4 类信息）
9. 用法示例
```

## 提交节奏

- 第 1 步：v3 spec 文档（本文）
- 第 2 步：用「减脂」跑 v3 验证
- 第 3 步：写 SKILL.md + tests
- 第 4 步：commit + PR
