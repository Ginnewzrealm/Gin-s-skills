# 钩子与悬念设计知识库（v1.0）

本文件是设计「结尾钩子」「主线钩」「母子钩子」时的**强制对照标准**。每设计一个钩子，必须逐条过三维定义与四大检验；任何一项 Fail 必须当场重写，禁止带病交付。

---

## 一、悬念的三维定义（缺一不可）

一个合格的悬念必须同时具备三个维度，缺任何一维即为废钩：

### 1. 认知缺口（Curiosity Gap）
- 读者明确知道「自己不知道什么」——缺口被命名、被看见，而不是模糊的"好像有秘密"。
- 合格：信息被具体地「扣住」——一个名字的下半截、一张照片被翻过去的那一面、一句被打断的话。
- 不合格：泛泛的"事情并不简单""背后另有隐情"——读者连缺口形状都看不见。

### 2. 情感赌注（Emotional Stakes）
- 缺口的答案必须与读者在乎的东西挂钩：主角的安危、执念、关系、代价。
- 检验句式："如果答案揭晓，主角会失去/得到/改变什么？"答不上来就是无赌注。
- 赌注要具体到人：不是"世界会毁灭"，而是"主角必须亲手指认一直信任的那个人"。

### 3. 即时反馈（Feedback Horizon）
- 读者必须能预期「这个钩子多久内有回音」——下一章、本卷内、还是终局。
- 每个钩子必须标注反馈窗口：短钩（1–3 章内兑现）、中钩（本卷内）、长钩（跨卷，必须配合周期性强化的子钩）。
- 没有任何回音预期的钩子，读者不会追，只会忘。

## 二、合格钩子的四大检验标准

每个钩子交付前，逐条对照：

### 检验一：刺痛神经（Specificity）
钩子必须有名词级的具体细节，拒绝空话。

| 判定 | 示例 |
|---|---|
| ❌ Fail | "他似乎发现了什么不得了的东西。" |
| ✅ Pass | "照片里那串编号，和他下一单的配送地址一模一样。" |

口诀：**删掉这个钩子，读者能否说出"主角到底看见了什么"？** 说不出来 → Fail。

### 检验二：绑定核心欲望（Desire Binding）
钩子必须挂在主角此刻最想得到/最害怕失去的东西上。

| 判定 | 示例 |
|---|---|
| ❌ Fail | "与此同时，某个神秘组织正在开会。"（与主角欲望无关的平行信息） |
| ✅ Pass | "名单上下一个名字，是他每天早上都会打招呼的人。" |

口诀：**这个钩子的答案，能否改变主角明天的行动？** 不能 → Fail。

### 检验三：可操作线索（Actionable Clue）
钩子给读者一个可以捏在手里的东西——物品、编号、半句话、一个反常细节——让读者能参与推理，而不是干等作者揭晓。

| 判定 | 示例 |
|---|---|
| ❌ Fail | "危险正在逼近。"（读者无从参与） |
| ✅ Pass | "客人退回的餐盒里多了一枚怀表，表盖上刻着真实的坐标。" |

口诀：**读者能不能拿着这条线索去群里跟人赌剧情？** 不能 → Fail。

### 检验四：母子钩子分层（Layered Hooks）
单一钩子不合格，必须分层：
- **子钩（短钩）**：本章/本单元闭环内兑现的小悬念，给即时满足感；
- **母钩（长钩）**：跨单元、跨卷的大悬念，从子钩中"长出来"，在子钩兑现时同步强化。

| 判定 | 示例 |
|---|---|
| ❌ Fail | 全书只有一个"幕后黑手是谁"从头挂到尾，中途无任何兑现。 |
| ✅ Pass | 单元结尾子钩兑现（编号被解码），但同时母钩强化（解码出的第一个坐标指向主角自己家）。 |

口诀：**子钩闭合的那一刻，母钩是否被拧紧了一格？** 没有 → 分层失败。

## 三、母子钩子与产出物回收机制的映射

本技能的「产出物编号 / 消费线 / 回收集数 / 回收方式」四列就是母子钩子的落地工具：

- **产出物 = 可操作线索的实体化**：每个钩子若产生实物/信息线索，必须登记产出物编号；
- **回收集数 = 反馈窗口的承诺**：填入回收集数，等于向读者承诺反馈窗口；留空的产出物即无窗口钩子，终局前必须清零；
- **回收方式 = 子钩兑现场景**：回收时必须同时完成「子钩闭合 + 母钩强化」两个动作，回收方式一栏应能看出这两个动作；
- **消费线跨线 = 母钩强化**：一条线的产出被另一条线消费时，天然构成母钩拧紧，优先用跨线消费做卷末钩。

## 四、钩子审计清单（交付前逐项打勾）

对每一个「结尾钩子」与「总攻阶段钩」执行：

```
钩子原文：________
[ ] 检验一·刺痛神经：删掉后读者能否说出主角看见了什么具体东西？
[ ] 检验二·绑定核心欲望：答案揭晓是否改变主角明天的行动？
[ ] 检验三·可操作线索：读者是否拿到一个可以赌剧情的实体线索？
[ ] 检验四·母子分层：本钩是子钩还是母钩？若是子钩，闭合时拧紧了哪个母钩？
[ ] 三维复查：认知缺口被命名了吗？情感赌注具体到人了吗？反馈窗口标了吗？
判定：Pass / Fail（Fail 项必须重写后重测）
```

**批量规则**：剧集总表中任何一行「结尾钩子」Fail，整表不得进入写飞书阶段。

## 五、连载即时反馈窗口规则

- **短钩（子钩）**：1–3 章内必须兑现或转化（转化为更大的钩也算兑现，但必须明示转化）；
- **中钩**：本卷内必须兑现，卷末允许保留 ≤ 1 个跨卷中钩；
- **长钩（母钩）**：跨卷悬挂期间，每 3–4 个单元必须有一次「强化触击」（新信息、新威胁、新代价三者之一），禁止静默悬挂；
- **反派同步动作**列同时承担母钩强化职责：反派每推进一步，母钩就拧紧一格。

## 六、常见废钩黑名单（直接判 Fail）

1. "事情并没有结束……"（无缺口形状、无线索、无赌注）
2. "他不知道的是，XX 正在暗中看着他。"（全知视角注水，主角无感知、读者无线索）
3. "一个神秘的电话打了进来。"（谁打的、说什么全无，纯拖延）
4. "更大的阴谋在等着他。"（形容词钩子，零信息量）
5. 与主线毫无咬合的单元内小反转（自嗨钩，不进产出物体系）
