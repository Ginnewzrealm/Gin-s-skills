# 黄金三章设计知识库（v2.0：输入侧方法论 + 输出侧标准 + 审计清单）

黄金三章的本质：**在 6000–10000 字内，完成一次精准的"读者签约"**——读者用三章判断这本书值不值得他花几十个小时，你要在这三章里把他"签"下来。

本文件三段式：**第一节先答七问（输入），第二节按规格装配（输出），第三节过审计（验收）**。七问不答清，不动笔设计。

---

## 第一节：七大输入（七问清单）

设计切入点候选之前，逐问作答。标注【须用户确认】的项，阶段 0 收集或阶段 2 开头补问；缺省时按类型默认值处理并标注"待确认"。其余项从大纲素材推导。

### 问 1：读者画像——给谁看？【须用户确认】
- 目标读者是谁？年龄/性别/阅读经验（老书虫还是轻度读者）？
- 什么场景读？通勤碎片化（节奏快、信息密度低）还是睡前沉浸（可加密）？
- 打开本书的心理预期？爽文要"代入感+即时反馈"，悬疑要"智力挑战+信息差"，言情要"情感张力+人物魅力"。
- 被什么劝退？老书虫怕套路感，轻度读者怕看不懂，所有人怕无聊。
> 不知道读者是谁，就不知道"黄金"的标准是什么。

### 问 2：类型公约——写什么赛道？【须用户确认】
- 本书类型是什么？该类型读者最期待前几章看到什么（如玄幻=金手指亮相+首次打脸；悬疑=一个不可能的案件）？
- 该类型开局禁忌是什么（如玄幻忌大段设定、悬疑忌无案日常）？
- 3–5 本同类型标杆书的前三章共性是什么？
> 类型公约决定及格线，不满足公约写得再花哨也是跑题。

### 问 3：人物锚点——读者凭什么在乎？
- 主角的**初始状态**：故事开始那一刻的处境切片（非完整小传）；
- 主角的**缺口**：缺钱/缺爱/缺认可/缺真相？缺口=共情入口；
- 主角的**反差**：最不可能做某事的人偏要做那件事；
- 主角的**声音**：说话方式、思考方式、面对压力的第一反应，前三章必须让读者"听见"；
- 代入**抓手**：靠处境（被欺负/被误解）还是靠欲望（想变强/想复仇）？
> 三章内读者不必了解主角全部，但必须"心疼他、好奇他、想成为他"——三者至少占一。

### 问 4：冲突引擎——凭什么往下看？
- **打破事件**：什么事件打破主角日常？必须反常、具体、有画面感（不是"人生发生改变"，而是"开门看见尸体，脸和他一模一样"）；
- **冲突三层**：表层（眼前具体问题，前三章必须启动）、中层（人际/利益博弈，必须暗示）、深层（价值观/身份认同，必须埋种）——与 `onion_narrative.md` 真相四层可互相映射；
- **赌注**：主角不行动会失去什么？必须具体、紧迫、不可逆；
- 三个章末钩子分别是什么（走 `hook_design.md` 四大检验）。

### 问 5：信息管控——给多少、藏多少？
- **必须交代**的只有四样：主角是谁、他在哪、他遇到什么事、他接下来要干嘛；其余全部推迟；
- **绝对禁止**：大段世界观、超过 5 个配角名字、复杂势力关系图、主角完整前史；
- **信息钩子化**：每条必给信息都包装成悬念（不说"世界有五大门派"，说"他死前只留一句：别去青云门"）；
- **信息差声明**：读者比主角多知道一点（紧张感）还是主角比读者多知道一点（好奇心）？选定一边并写明。

### 问 6：情绪曲线——感受怎么走？
- 第一章基调：好奇+轻微不安；第二章：紧张+共情（读者开始替主角着急）；第三章高点：震撼+渴望（"卧槽原来是这样"）；
- **呼吸点**：连续高压后要有短暂松弛（一句幽默、一个温暖细节），没有呼吸点读者会情绪疲劳。

### 问 7：结构骨架——怎么排列？
- **开篇第一句话/第一个画面**：整本书最重要的一句话，三秒抓注意力；最好是动作或反常画面，最差是天气描写或感慨抒情；
- **不可逆点**：第三章中后段，主角做一个决定/说一句话/发生一件事，从此回不了头——这个点之后，故事正式开始；
- 三章结构是一个**漏斗**：从宽（日常）到窄（冲突）到一个点（不可逆选择），读者被吸进去出不来。

## 第二节：输出侧标准（三章分工 · 钩子/磁铁/炸弹）

一句话总纲：**第一章要像钩子，第二章要像磁铁，第三章要像炸弹。**总量 6000–10000 字。

### 第一章：抛出危机，抓住眼球（钩子）
**功能**：建立"这个人+这个处境+这个反常事件"，前 1000 字内启动冲突，500 字内展现主角遭遇的变故或转折，明确第一个目标。
- **冲突公式：危机 + 反常 + 代价**；
- **人设速成**：用"非常态反应"立人设，不写"他很冷静"；
- 情绪基调：好奇+轻微不安；
- 章末抛出第一个大悬念。

### 第二章：展现能力，制造反转（磁铁）
**功能**：主角被迫行动，前 3000 字（累计）内冲突升级；解决第一个阶段性困境展现能力，带来第一个爽点；引入关键配角或对手（控制人名总数 ≤5）。
- **世界观渗透·冰山法则**：只露 10%，靠行动与对话带出；
- **悬念链顶针递进**（见 `onion_narrative.md` 第三节）；
- 情绪走向：紧张+共情；
- 章末出现第一个反转。

### 第三章：升级冲突，诱导付费（炸弹）
**功能**：冲突升级到"不翻第四章就睡不着"的临界点；中后段放置**不可逆点**；暗示更大的世界/更深的秘密。
- **认知颠覆**：信任的人背叛，或颠覆主角认知的秘密；
- **双重困境**："救人还是自保"式终极拷问；
- 情绪高点：震撼+渴望；
- 章末钩子是前三章最强的一个，直通第四章。

### 避坑指南（五要五不要）
| 要 | 不要 |
|---|---|
| 现在进行时：从当下的危机开写 | 回忆杀：从"十年前"开始 |
| 动作和冲突：用事件推动剧情 | 大段内心独白：靠主角碎碎念 |
| 藏九露一：设定融入剧情 | 世界观大百科：像说明书一样交代 |
| 反常细节：独特细节立人物立场景 | 陈词滥调：老套描写 |
| 单一视角：死磕主角视角探索世界 | 上帝视角乱飞 |

## 第三节：审计清单（交付前逐项打勾）

```
【输入侧】
[ ] 七问全部作答？须用户确认项已确认或标"待确认"？
[ ] 类型公约首付在前三章兑现？开局禁忌零踩雷？
[ ] 信息差方向已声明（读者>主角 或 主角>读者）？

【第一章·钩子】
[ ] 开篇第一句是动作或反常画面（非天气/抒情）？
[ ] 前 1000 字内启动冲突？500 字内出变故、目标明确？
[ ] 冲突公式三件套：危机 + 反常 + 代价？
[ ] 人设靠"非常态反应"立？无大段设定、无回忆杀？
[ ] 章末钩子通过 hook_design.md 四大检验？

【第二章·磁铁】
[ ] 主角解决阶段性困境，展现能力/金手指？有爽点？
[ ] 世界观渗透 ≤10%，靠行动对话带出？
[ ] 悬念链至少两环顶针衔接？结尾有第一个反转？
[ ] 章末钩子通过四大检验？

【第三章·炸弹】
[ ] 不可逆点在中后段（主角回不了头）？
[ ] 认知颠覆或双重困境至少其一？
[ ] 冲突达"不翻第四章睡不着"临界点？
[ ] 章末钩子为前三章最强且过四大检验？

【量化红线】
[ ] 总量 6000–10000 字？
[ ] 前三章人名 ≤5 个？
[ ] 无超过三行的纯设定/纯描写/纯议论？
[ ] 每段都通过"删掉是否影响阅读"测试？

【外部视角 8 问】
[ ] 读完第一章，能用一句话说出"这个人在干嘛"？
[ ] 读完第二章，有"替主角着急"的感觉？
[ ] 读完第三章，有"不翻第四章就难受"的冲动？
[ ] 不了解本书的人能说出"这本书大概讲什么"？
[ ] 冲突三层：表层启动、中层暗示、深层埋种？
[ ] 情绪有呼吸点，非全程高压？
[ ] 三项代入（心疼/好奇/想成为）至少占一？
[ ] 三章钩子构成"短钩→中钩→母钩"衔接链？
判定：Pass / Fail（Fail 项重写后重测）
```

## 附：与本技能流程的衔接

- **阶段 0**：输入表收集读者画像与类型公约（问 1、2），缺省按类型默认值并标"待确认"；
- **阶段 2**：候选方案生成前先答七问；每个候选附六项核心目标自评（冲突前置/明确目标/代入感/紧迫感/能力展示/章末钩子，答不上标红）；选定后逐章按第二节规格细化，过第三节审计；
- **代价提示**：被放弃候选的独有铺垫优势，写明在后文第几章以什么方式回补（顶针衔接，见 `onion_narrative.md`）。
