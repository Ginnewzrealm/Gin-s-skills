# 剥洋葱叙事知识库（真相分层与顶针悬念，v1.0）

本文件规定本技能设计「单元剧悬念链」与「主线真相结构」时的**强制分层标准**。每个单元的解谜结构、每条主线的真相释放节奏、相邻单元钩子的衔接方式，都必须对照本文件设计并接受审计。

---

## 一、核心手法三件套

### 1. 剥笋脱壳法（层层剥笋）
由果到因、由表及里：随情节展开剥去表面现象与疑云迷雾，逐渐显露原因、真相和本质。符合读者认知过程，让读者顺理成章跟随剧情。

### 2. 洋葱叙事（Onion Narrative）
- **层层递进**：真相有多层。剥开现象 → 看到动机 → 触及结构 → 抵达根源。
- **高级变体·空心洋葱**：真相不是绝对实体，随视角和认知变化不断重构——让故事从"解谜"上升到人性或哲学层面。每条主线至少在根源层预留一次"重构反转"的可能。
- **成功判据**：洋葱式悬疑的成败不在故事多曲折，而在**每剥开一层，读者对人物的理解被刷新一次**——"事件真相"的揭晓必须服务于"情感真相"的抵达。

### 3. 顶针式悬念（层层推进）
上一个悬念的末尾，紧接成为下一个悬念的开头。情节发展中逐步排除各种可能性，像剥茧抽丝层层展开，直到出人意料又在情理之中的结局。

---

## 二、真相四层模型（每个单元与每条主线共用）

| 层 | 问题 | 作用 | 网文例 |
|---|---|---|---|
| 第一层·现象 | 发生了什么？ | 建立初始悬念与好奇心 | 主角目睹离奇灭门案 / 收到诡异信件 |
| 第二层·动机 | 为什么会这样？ | 开始颠覆读者初步认知 | 惨案并非仇杀，是为掩盖某个身份 |
| 第三层·结构 | 背后的网络是什么？ | 从个人恩怨上升到利益网络或组织 | 动机牵扯庞大组织 / 数十年阴谋 |
| 第四层·根源 | 最核心的本质是什么？ | 上升到人性/哲学/存在层面 | 阴谋根源只是某人青春期的一次心理误判 |

**层级分配规则**：
- **单元剧**：常规单元至少剥到第二层（动机）；主线浓度"中"的单元剥到第三层（结构）一角；浓度"高"的单元必须让某层真相"刷新人物理解"。
- **主线**：绝对主线的四层必须完整且分布在全书节奏上——现象层开篇即抛、动机层前半程逐格揭露、结构层在中点前后全貌浮现、根源层留给终局（总攻阶段）。
- **延迟解码**：通过碎片化信息、多线索交织或多层时间结构，让读者与主角**同步**拼凑线索——禁止主角或作者单方面"宣布真相"。

---

## 三、顶针衔接规则（单元之间）

- **钩尾接头**：第 N 单元「结尾钩子」抛出的悬念，必须是第 N+1（或明确指定集数）单元开局要接的"头"——接钩集数在「回收方式」或「消费线」中可追溯。
- **排除法推进**：每个单元至少排除一种错误可能性（假线索被证伪也是进展），禁止原地打转。
- **子钩兑现已定义在 hook_design.md**：子钩闭合 = 剥开一层；闭合时必须拧紧母钩 = 露出下一层。两份文件的规则互为表里，审计时合并执行。
- **断针检查**：任何一个钩子若没有任何后续单元接它，即"断针"，等同 hook_design.md 的"无反馈窗口钩子"，判 Fail。

## 四、实操三技巧

1. **伏笔程序化**：关键线索藏在看似客观的"系统提示""日常对话""环境描写"里，不用作者主观旁白暗示。（映射：产出物尽量以"物"而非"台词"的形式存在。）
2. **视角多声部**：同一事件在不同角色视角下呈现完全不同面貌，通过视角切换让真相立体。（映射：「人物代价」与「反派同步动作」两列是天然的多声部载体。）
3. **节奏反高潮**：读者以为要大高潮时，用一个平常细节或反转"泄力"，换取更持久的回味与震撼。每卷至多使用一次，连用即失效。

## 五、剥洋葱审计清单（并入钩子审计关卡执行）

```
【单单元】
[ ] 本单元剥到了第几层？与该单元"主线浓度"档位匹配吗？
[ ] 至少排除了一种错误可能性（排除法推进）？
[ ] 若浓度为"高"：本层真相是否刷新了读者对某人物的理解？

【单元衔接】
[ ] 上一单元结尾钩子有明确单元接钩（无断针）？
[ ] 本单元结尾钩子的"钩尾"能被下一单元当"头"接住？

【主线全卷】
[ ] 绝对主线四层分布：现象（开篇）/ 动机（前半程）/ 结构（中点）/ 根源（终局）？
[ ] 结构层是否在主角行动网中"线索相互印证"，而非单次爆料？
[ ] 根源层是否落到人（人性/心理），而非落到"更大的组织"套娃？
[ ] 延迟解码成立：读者与主角同步拼凑，无单方面宣布真相？
判定：Pass / Fail（Fail 项重写后重测）
```
